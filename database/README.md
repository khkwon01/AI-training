기초 개념 → 모델링 → SQL → 트랜잭션/정합성 → 성능/운영 → 최신 이슈 순서로 설계했어요.

  주차별 주제 제안 (15회)

  1. 데이터베이스 개요: 데이터/정보, DBMS 역할, 관계형 모델 기본
  2. 요구사항 분석 & ER 모델링(개체, 속성, 관계, 카디널리티)
  3. ER → 관계형 스키마 변환 규칙
  4. 정규화 1: 함수적 종속, 1NF~3NF
  5. 정규화 2: BCNF, 역정규화 개념
  6. SQL 기본 1: SELECT, WHERE, JOIN, 집계
  7. SQL 기본 2: 서브쿼리, 뷰, 집합 연산
  8. SQL 고급: 제약조건, 트리거, 프로시저 개요
  9. 인덱스와 저장 구조: B-Tree, 해시, 클러스터링
  10. 쿼리 처리: 옵티마이저, 실행계획 읽기
  11. 트랜잭션 1: ACID, 동시성 제어, 락
  12. 트랜잭션 2: 격리수준, 데드락, 복구
  13. 분산 DB/복제/샤딩 개요
  14. NoSQL 개요: 키-값, 문서, 컬럼, 그래프 비교
  15. 최신 주제 & 종합: 데이터 웨어하우스/레이크, 성능 튜닝 사례, 리뷰

  원하시면 다음 중 하나로 더 구체화해 드릴게요.

  1. 실습 중심(예: PostgreSQL/MySQL)으로 과제·실습까지 포함한 주차별 과제 설계
  2. 이론 중심으로 시험/퀴즈용 핵심 개념 목록 정리
  3. 학부/대학원 수준에 맞춘 난이도 조정
