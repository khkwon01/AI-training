# Chapter 02: AI와 함께 코드 만드는 실제 루프

## 이 장에서 배우는 것

- AI 코딩 루프의 핵심 원칙: 작게 요청하기
- 요청 → 초안 확인 → 실행 → 수정의 각 단계를 상세히
- "한 번에 다 만들어줘" vs "하나씩 만들어줘" 비교 (실패/성공 사례)
- AI에게 요청할 때 좋은 예시 vs 나쁜 예시 5쌍
- 초안을 받았을 때 확인해야 할 것들
- 실습 3개: 함수 1개씩 요청해서 메모 서비스 만들기

## 왜 AI 코딩 루프가 필요한가?

AI에게 "인스타그램 앱 만들어줘"라고 하면 어떤 코드가 나올까?

코드는 나온다. 하지만 이런 일이 생긴다.

- 수백 줄짜리 코드가 한꺼번에 나와서 어디서 시작해야 할지 모른다
- 실행해보면 여러 오류가 동시에 나온다
- 어느 부분이 문제인지 파악하기 어렵다
- 고치다 보면 무엇을 고쳤는지 추적이 안 된다
- 결국 처음부터 다시 해야 하는 경우가 많다

반대로 "메모 하나를 리스트에 저장하는 함수만 만들어줘"라고 하면:

- 코드가 10줄 이내로 나온다
- 한 눈에 읽고 이해할 수 있다
- 실행해서 바로 확인할 수 있다
- 잘 되면 다음 단계로, 안 되면 이 단계만 고친다
- 전체 완성까지 단계별로 쌓아갈 수 있다

**AI와 함께 코딩할 때는 작게 쪼개서 대화해야 한다.** 요리를 배울 때 "프랑스 코스 요리 만들어줘"가 아니라 "양파 반달 모양으로 써는 법 알려줘"처럼.

## 1. AI 코딩 루프의 핵심 원칙: 작게 요청하기

### 왜 작게 쪼개야 하나?

AI는 요청한 모든 것을 한 번에 처리하려고 한다. 요청이 클수록:
- AI가 가정해서 채워넣는 부분이 많아진다 (내 의도와 다를 수 있다)
- 코드가 길어져서 검증하기 어렵다
- 오류가 여러 곳에 퍼져있어서 찾기 어렵다
- 어디까지 완성된 건지 파악하기 어렵다

**작게 쪼개면:**
- AI의 응답이 짧아서 읽고 이해하기 쉽다
- 실행해서 즉시 검증할 수 있다
- 문제가 생기면 어느 단계인지 즉시 파악된다
- 단계별로 쌓아가므로 진행 상황을 명확히 알 수 있다

### 기능 쪼개기 원칙

AI에게 요청하기 전에 먼저 기능을 독립적인 단위로 나눈다.

**나쁜 방식: 한 번에 전부 요청**
```
메모를 저장하고, 조회하고, 삭제하고, 파일에도 저장되는 메모 앱 만들어줘.
```

**좋은 방식: 단계별로 쪼개기**
```
1단계: 메모 하나를 리스트에 저장하는 add_memo(text) 함수
2단계: 저장된 메모를 번호와 함께 출력하는 show_memos() 함수
3단계: 번호로 메모를 삭제하는 delete_memo(index) 함수
4단계: 메모를 파일에 저장/불러오는 save_memos(), load_memos() 함수
5단계: 위 함수들을 연결하는 메뉴 루프
```

각 단계가 독립적으로 동작하는지 확인하고 다음 단계로 넘어간다.

## 2. "한 번에 다 만들어줘" vs "하나씩 만들어줘" 비교

### 실패 사례: 한 번에 요청

```
사용자: Python으로 메모 앱 만들어줘. 메모 추가, 조회, 삭제, 수정, 파일 저장, 검색 기능 포함해서.
```

AI가 돌려주는 코드 (약 120줄):

```python
import json
import os
from datetime import datetime

MEMO_FILE = "memos.json"

class MemoManager:
    def __init__(self):
        self.memos = self.load_memos()
    
    def load_memos(self):
        if os.path.exists(MEMO_FILE):
            with open(MEMO_FILE, 'r', encoding='utf-8') as f:
                return json.load(f)
        return []
    
    def save_memos(self):
        with open(MEMO_FILE, 'w', encoding='utf-8') as f:
            json.dump(self.memos, f, ensure_ascii=False, indent=2)
    
    def add_memo(self, text):
        memo = {
            "id": len(self.memos) + 1,
            "text": text,
            "created_at": datetime.now().isoformat(),
            "updated_at": datetime.now().isoformat()
        }
        self.memos.append(memo)
        self.save_memos()
        print(f"메모 추가: {text}")
    
    def show_memos(self):
        if not self.memos:
            print("저장된 메모가 없습니다.")
            return
        for memo in self.memos:
            print(f"[{memo['id']}] {memo['text']} ({memo['created_at'][:10]})")
    
    # ... (이하 60줄 더 계속)
```

**이때 발생하는 문제들:**
- `class`가 뭔지 모르면 코드 자체를 이해할 수 없다
- `import json`, `os`, `datetime`이 왜 필요한지 설명이 없다
- 실행해봤더니 `json.JSONDecodeError`가 나는데 원인을 모른다
- 어느 부분을 수정해야 할지 전혀 감이 안 온다
- 결국 AI에게 "고쳐줘"만 반복하다가 이해 없이 코드만 쌓인다

### 성공 사례: 하나씩 요청

**1단계 요청:**
```
Python으로 메모 하나를 리스트에 저장하는 함수를 만들어줘.
함수 이름은 add_memo이고, 매개변수는 text야.
초보자도 이해할 수 있게 주석도 추가해줘.
```

AI 응답 (약 12줄):
```python
# 메모를 저장하는 리스트
memos = []

def add_memo(text):
    """
    새 메모를 리스트에 추가하는 함수
    매개변수: text (str) - 저장할 메모 내용
    """
    memos.append(text)
    print(f"메모 저장 완료: {text}")
```

**이때의 장점:**
- 12줄이라 한 눈에 읽을 수 있다
- 각 줄이 무엇을 하는지 이해할 수 있다
- 바로 실행해서 작동 확인이 가능하다
- 이해가 안 되는 부분이 있으면 AI에게 바로 물어볼 수 있다

1단계가 잘 동작하면 2단계 요청:
```
add_memo 함수가 잘 동작해. 이번엔 저장된 메모 전체를 번호와 함께 출력하는 show_memos() 함수를 추가해줘.
```

이렇게 단계별로 쌓아가면 전체 완성까지 가면서도 각 단계를 완전히 이해할 수 있다.

## 3. AI에게 요청할 때: 좋은 예시 vs 나쁜 예시 5쌍

### 쌍 1: 범위 명확하게

**나쁜 요청:**
```
메모 앱 만들어줘.
```

**좋은 요청:**
```
Python으로 메모 하나를 리스트에 저장하는 add_memo(text) 함수만 만들어줘.
다른 기능은 나중에 따로 요청할게.
```

이유: 범위가 명확하지 않으면 AI가 필요 이상으로 많은 것을 만든다.

---

### 쌍 2: 조건과 제약 명시

**나쁜 요청:**
```
숫자를 받아서 처리하는 함수 만들어줘.
```

**좋은 요청:**
```
두 정수를 받아서 나눗셈 결과를 반환하는 divide(a, b) 함수를 만들어줘.
b가 0이면 "0으로 나눌 수 없습니다"를 출력하고 None을 반환해야 해.
```

이유: 조건과 예외 처리를 명시하면 의도에 맞는 코드가 나온다.

---

### 쌍 3: 현재 상황을 포함

**나쁜 요청:**
```
오류 고쳐줘.
```

**좋은 요청:**
```
아래 코드를 실행했더니 이런 오류가 나왔어:

코드:
def add_memo(text):
    memos.append(text)

오류:
NameError: name 'memos' is not defined

왜 이 오류가 나는지, 어떻게 고쳐야 하는지 설명해줘.
```

이유: 오류 메시지와 코드를 함께 보내야 AI가 정확하게 진단할 수 있다.

---

### 쌍 4: 수준과 스타일 명시

**나쁜 요청:**
```
이 코드 설명해줘.
```

**좋은 요청:**
```
아래 코드를 초보자가 이해할 수 있는 수준으로 한 줄씩 설명해줘.
특히 memos.append(text) 부분이 뭔지 모르겠어.

코드:
memos = []

def add_memo(text):
    memos.append(text)
    print(f"메모 저장 완료: {text}")
```

이유: 수준을 명시하면 너무 어렵거나 너무 쉬운 설명이 나오지 않는다.

---

### 쌍 5: 테스트 코드 요청

**나쁜 요청:**
```
add_memo 함수 만들어줘.
```

**좋은 요청:**
```
add_memo(text) 함수를 만들어줘. 함수 아래에 테스트 코드도 추가해줘.
"Python 공부하기"와 "운동하기" 두 개를 추가하고, 추가 후에 memos 리스트를 출력해서 확인할 수 있게.
```

이유: 테스트 코드를 함께 요청하면 실행해서 즉시 확인할 수 있다.

## 4. 요청 → 초안 확인 → 실행 → 수정 루프

AI와 함께 작업할 때의 전체 흐름이다.

### 단계 1: 요청하기

작게 쪼갠 기능 하나를 구체적으로 요청한다. 앞서 배운 좋은 요청 방식을 사용한다.

### 단계 2: 초안 확인하기 (코드 읽기)

AI가 코드를 주면 바로 실행하지 말고 먼저 읽는다.

**확인할 항목:**

```
체크리스트:
[ ] 함수 이름이 내가 요청한 것과 맞는가?
[ ] 매개변수가 맞는가?
[ ] 내가 기대한 동작을 하는 코드인가?
[ ] import가 있다면 왜 필요한지 이해하는가?
[ ] 이해 안 되는 부분이 있는가?
[ ] 주석이 있는가 (없으면 AI에게 요청)?
```

이해 안 되는 부분이 있으면 실행 전에 AI에게 먼저 물어본다.

```
memos.append(text) 에서 append가 뭔지 모르겠어. 쉽게 설명해줘.
```

### 단계 3: 실행하기

이해가 됐으면 파일에 붙여넣고 실행한다. 이때 AI가 준 코드만 있으면 테스트를 추가한다.

```python
# AI가 준 코드
memos = []

def add_memo(text):
    memos.append(text)
    print(f"메모 저장 완료: {text}")

# 직접 테스트 추가
add_memo("Python 공부하기")
add_memo("운동하기")
print("현재 메모:", memos)
```

```bash
python3 memo.py
```

예상 출력:
```
메모 저장 완료: Python 공부하기
메모 저장 완료: 운동하기
현재 메모: ['Python 공부하기', '운동하기']
```

### 단계 4: 수정하거나 다음 요청하기

**잘 동작한다면:** 다음 기능을 요청한다.

```
좋아. add_memo가 잘 동작해. 이번엔 저장된 메모를 번호와 함께 출력하는 show_memos() 함수를 추가해줘.
```

**원하는 동작이 아니라면:** 구체적으로 어떻게 달랐는지 설명한다.

```
add_memo가 동작하긴 하는데, 같은 메모를 두 번 추가하면 두 번 저장되더라.
중복을 방지하고 싶어. 이미 있는 내용이면 "이미 있는 메모입니다"라고 출력해줘.
```

**오류가 났다면:** 오류 메시지를 그대로 붙여넣는다.

```
실행했더니 이런 오류가 나왔어:

NameError: name 'memos' is not defined

왜 이런 오류가 나는지 설명해줘.
```

## 5. AI가 틀렸을 때 대화 이어가기

AI가 항상 원하는 코드를 주지는 않는다. 틀렸을 때 대화를 이어가는 방법이 중요하다.

### "고쳐줘"만 반복하면 생기는 문제

```
사용자: 이거 고쳐줘
AI: (수정된 코드)
사용자: 이거 고쳐줘
AI: (또 수정된 코드)
사용자: 이거 고쳐줘
```

이렇게 반복하면:
- 코드는 실행될 수 있지만 왜 동작하는지 모른다
- 다음에 비슷한 문제가 생기면 또 AI에게 의존해야 한다
- 코드 이해도가 전혀 늘지 않는다

### 더 나은 방법: 원인과 이유 요청

```
이 오류가 왜 나는지 먼저 설명해줘. 이해하고 싶어.

NameError: name 'memos' is not defined
```

```
수정하기 전에, 현재 코드에서 어떤 부분이 문제인지 한 줄로 설명해줘.
```

```
고쳐준 코드에서 기존 코드랑 다른 부분을 표시해줘. 무엇이 바뀌었는지 알고 싶어.
```

## 6. Copilot vs Claude: 어떤 상황에서?

| 상황 | 추천 도구 | 이유 |
|------|----------|------|
| VS Code에서 코딩 중 다음 줄 자동완성 | GitHub Copilot | 에디터에 내장, 타이핑하면 바로 제안 |
| 함수 이름만 쓰고 내용 완성 | GitHub Copilot | 현재 파일 컨텍스트를 잘 파악함 |
| 긴 설명과 함께 코드 요청 | Claude / ChatGPT | 대화형으로 요구사항 조율 가능 |
| 오류 메시지 분석 요청 | Claude / ChatGPT | 맥락을 설명하며 대화 가능 |
| 코드 전체 구조 리뷰 | Claude / ChatGPT | 긴 코드와 맥락 설명을 함께 보낼 수 있음 |
| 처음 보는 코드 설명 요청 | 둘 다 가능 | Claude는 더 자세한 설명 |
| 테스트 코드 자동 생성 | GitHub Copilot | 기존 코드 패턴을 바탕으로 생성 |

## 실습

### 실습 1: 메모 서비스 함수 하나씩 만들기 (따라 하기)

AI(Claude 또는 Copilot)에게 아래 순서대로 요청하면서 `memo_service.py`를 단계별로 완성한다.

**1단계 요청:**

Claude나 ChatGPT에게 아래를 입력한다.

```
Python으로 메모 하나를 리스트에 저장하는 함수를 만들어줘.
- 함수 이름: add_memo
- 매개변수: text (저장할 메모 내용)
- 메모를 추가하면 "메모 저장: (내용)" 이라고 출력해줘
- 함수 아래에 "Python 공부하기"를 추가하는 테스트 코드도 써줘
- 초보자도 이해할 수 있게 각 줄에 주석 달아줘
```

AI 초안을 받으면:
1. 코드를 읽는다 (이해 안 되는 줄이 있으면 물어본다)
2. `memo_service.py`에 붙여넣는다
3. `python3 memo_service.py`로 실행한다
4. 예상 출력이 나오면 2단계로 진행한다

예상 출력:
```
메모 저장: Python 공부하기
```

**2단계 요청 (1단계가 잘 동작하면):**

```
add_memo 함수가 잘 동작해. 다음 기능을 추가해줘.
저장된 메모 전체를 번호와 함께 출력하는 show_memos() 함수가 필요해.
예시:
  1. Python 공부하기
  2. 운동하기
메모가 없으면 "저장된 메모가 없습니다"를 출력해줘.
테스트 코드도 포함해줘.
```

AI 응답을 `memo_service.py`에 추가하고 실행한다.

예상 출력:
```
1. Python 공부하기
2. 운동하기
```

**3단계 요청 (2단계가 잘 동작하면):**

```
add_memo, show_memos 함수가 잘 동작해. 마지막으로 while 루프를 추가해줘.
- 사용자가 "quit"을 입력할 때까지 계속 루프를 돈다
- 매 반복마다 사용자에게 메모를 입력받는다
- 입력한 내용을 add_memo로 저장한다
- 저장 후 show_memos로 현재 목록을 출력한다
- "quit"을 입력하면 "프로그램을 종료합니다"를 출력하고 종료한다
```

예상 실행 흐름:

### 실습 2: AI가 준 코드 설명 요청하기 (따라 하기)

실습 1의 1단계에서 받은 코드를 AI에게 다시 보내며:

```
아래 코드를 초보자 수준으로 한 줄씩 설명해줘.
특히 memos.append(text)와 f"메모 저장: {text}" 부분이 뭔지 모르겠어.

(코드 붙여넣기)
```

설명을 읽고 각 줄이 무엇을 하는지 자신의 말로 설명할 수 있을 때까지 확인한다.

**직접 해보기:** 설명을 들은 후, AI 없이 직접 `add_memo` 함수를 처음부터 타이핑해보자. 이해한 내용을 바탕으로 주석도 직접 달아본다.

### 실습 3: 의도적으로 오류 만들고 해결하기 (따라 하기)

`memo_service.py`에서 다음 실험을 해보자.

**실험 1: 정수를 메모로 추가하기**

```python
add_memo(123)  # 문자열 대신 숫자를 넣으면?
```

실행해서 어떤 결과가 나오는지 확인한다. 오류가 나면 AI에게:

```
add_memo(123)을 실행했더니 아래 오류가 나왔어.
이 오류가 왜 나는지 설명해줘. 그리고 숫자를 넣어도 문자열로 변환해서 저장하려면 어떻게 해야 해?

(오류 메시지 붙여넣기)
```

**실험 2: 변수 이름을 일부러 틀리게 쓰기**

`memos.append(text)` 줄에서 `memos`를 `memo`로 바꿔보자.

```python
def add_memo(text):
    memo.append(text)   # memos → memo로 변경 (일부러 틀리게)
    print(f"메모 저장: {text}")
```

실행하면 어떤 오류가 나는지 확인하고, AI에게 오류 메시지를 보내서 원인을 물어본다.

**실험 3: 빈 리스트에서 삭제 시도**

아직 `delete_memo` 기능을 만들지 않았다면, AI에게 요청해보자.

```
번호로 메모를 삭제하는 delete_memo(index) 함수를 추가해줘.
존재하지 않는 번호를 입력하면 "잘못된 번호입니다"라고 출력해줘.
번호는 show_memos에서 보이는 번호 (1부터 시작)를 입력받는 거야.
```

받은 코드를 실행하고, 존재하지 않는 번호(예: 100)를 입력해서 예외 처리가 잘 되는지 확인한다.

## 자주 하는 실수 정리표

| 실수 | 결과 | 해결 방법 |
|------|------|----------|
| 큰 기능을 한 번에 요청 | 이해 못 하는 긴 코드 | 독립적인 기능 단위로 쪼개서 요청 |
| AI 코드를 읽지 않고 바로 실행 | 오류 원인 찾기 어려움 | 한 줄씩 읽고 이해 후 실행 |
| 오류 없이 실행된다고 완성 | 결과가 틀릴 수 있음 | 실제 값 출력하며 의도한 결과인지 확인 |
| "고쳐줘"만 반복 | 코드 이해 없이 진행 | 고친 이유를 AI에게 설명 요청 |
| 오류 메시지 없이 "안 돼요" | AI가 정확한 도움 불가 | 오류 메시지 전체를 복사해서 붙여넣기 |
| 여러 기능을 한 파일에 섞어서 요청 | 흐름이 엉킴 | 기능 하나가 완성되면 다음 기능으로 |

## 확인 체크리스트

- [ ] AI에게 요청하기 전에 기능을 작은 단위로 나눌 수 있는가
- [ ] "좋은 요청 vs 나쁜 요청"의 차이를 말할 수 있는가
- [ ] AI가 준 코드를 받으면 바로 실행하지 않고 먼저 읽는가
- [ ] 이해 안 되는 줄이 있으면 AI에게 설명을 요청하는가
- [ ] 코드를 실행해서 원하는 결과가 나오는지 직접 확인하는가
- [ ] 오류가 났을 때 오류 메시지를 AI에게 붙여넣고 원인을 물어보는가
- [ ] 단계별로 기능을 추가하며 전체 프로그램을 완성할 수 있는가
- [ ] 메모 서비스 3단계 실습을 완성했는가
