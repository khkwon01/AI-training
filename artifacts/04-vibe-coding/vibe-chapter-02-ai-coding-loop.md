# Chapter 02: AI와 함께 코드 만드는 실제 루프

## 이 장에서 배우는 것

- AI에게 기능을 요청하는 좋은 방법과 나쁜 방법
- 요청 → 초안 확인 → 수정 → 실행 → 다음 단계 루프를 실제로 돌리는 방법
- 한 번에 큰 것을 요청하지 않고 작게 쪼개는 이유
- AI가 틀렸을 때 어떻게 대화를 이어가는지
- Copilot, Claude 각각을 어떤 상황에서 쓰면 좋은지

---

## 먼저 쉬운 설명

AI에게 "인스타그램 앱 만들어줘"라고 하면 어떤 코드가 나올까?

나오긴 나온다. 하지만 수백 줄짜리 코드가 나오고, 어디서 시작해야 할지 모르고, 실행해보면 오류가 나고, 고치다 보면 뭘 고쳤는지도 모르게 된다.

AI와 함께 코딩할 때는 **작게 쪼개서** 대화해야 한다. 요리를 배울 때 "프랑스 코스 요리 만들어줘"가 아니라 "양파 반달 모양으로 써는 법 알려줘"처럼.

이 장에서는 작은 기능 하나를 AI와 함께 단계별로 만드는 전체 루프를 실습한다.

---

## 1. 요청 전에 먼저 할 일: 기능 쪼개기

어떤 기능이든 AI에게 요청하기 전에 먼저 작은 단위로 나눈다.

### 나쁜 요청
```
할일 관리 앱 만들어줘.
```

### 좋은 요청 순서
```
1단계: 할일 하나를 저장하는 함수 만들어줘
2단계: 저장된 할일 목록을 출력하는 함수 만들어줘
3단계: 특정 할일을 완료 처리하는 함수 만들어줘
4단계: 세 함수를 연결해서 간단한 메뉴 만들어줘
```

각 단계가 독립적으로 동작하는지 확인하고 다음 단계로 넘어간다.

---

## 2. 요청 → 초안 → 확인 → 수정 루프

### 실습 예제: 메모 저장 기능 만들기

**1단계. 요청하기**

Claude 또는 Copilot에게:

```
Python으로 메모 하나를 리스트에 저장하는 함수를 만들어줘.
함수 이름은 add_memo이고, 매개변수는 text야.
초보자도 이해할 수 있게 주석도 추가해줘.
```

**2단계. 초안 확인하기**

AI가 아래처럼 응답할 수 있다.

```python
# 메모를 저장하는 리스트
memos = []

def add_memo(text):
    """
    새 메모를 리스트에 추가하는 함수
    
    매개변수:
        text (str): 저장할 메모 내용
    """
    memos.append(text)
    print(f"메모 저장 완료: {text}")
```

코드를 읽으며 체크할 것:
- [ ] 함수 이름이 맞는가 (`add_memo`)
- [ ] 매개변수가 맞는가 (`text`)
- [ ] 내가 기대한 동작인가 (리스트에 추가)
- [ ] 이해 안 되는 부분이 있는가

**3단계. 직접 실행하기**

`memo.py` 파일에 코드를 붙여넣고 실행한다.

```python
memos = []

def add_memo(text):
    memos.append(text)
    print(f"메모 저장 완료: {text}")

# 테스트
add_memo("Python 공부하기")
add_memo("GitHub 연습하기")
print(memos)
```

```bash
python3 memo.py
```

예상 출력:
```
메모 저장 완료: Python 공부하기
메모 저장 완료: GitHub 연습하기
['Python 공부하기', 'GitHub 연습하기']
```

**4단계. 수정하거나 다음 요청하기**

잘 동작하면 다음 단계로 넘어간다.

```
좋아. 이제 저장된 메모 전체를 번호와 함께 출력하는 함수 show_memos를 추가해줘.
```

## 3. AI가 틀렸을 때 대화 이어가기

AI가 항상 원하는 코드를 주지는 않는다. 틀렸을 때 대화를 이어가는 방법이 중요하다.

### 오류가 났을 때

오류 메시지를 그대로 붙여넣고 설명을 요청한다.

```
실행했더니 이런 오류가 나왔어:

NameError: name 'memos' is not defined

왜 이런 오류가 나는지 설명해줘.
```

### 원하는 동작이 아닐 때

구체적으로 어떻게 달랐는지 설명한다.

```
add_memo 함수가 잘 동작하는데, 같은 메모를 두 번 추가하면 두 번 저장되더라.
중복을 방지하고 싶어. 같은 내용이 이미 있으면 "이미 있는 메모입니다"라고 출력해줘.
```

### 이해가 안 될 때

```
memos.append(text) 에서 append가 뭔지 모르겠어. 쉽게 설명해줘.
```

## 4. Copilot vs Claude 어떤 상황에서?

| 상황 | 추천 도구 |
|------|----------|
| VS Code에서 코딩 중 다음 줄 제안 받기 | Copilot (자동완성) |
| 함수 이름만 쓰고 내용 완성하기 | Copilot (자동완성) |
| 긴 설명과 함께 코드 요청하기 | Claude / ChatGPT |
| 오류 메시지 분석 요청 | Claude / ChatGPT |
| 코드 전체 구조 리뷰 받기 | Claude / ChatGPT |
| 주석 달린 코드 설명 요청 | 둘 다 가능 |

## 5. 따라 하기 실습

### 실습 1. 메모 앱 3단계로 만들기

아래 순서대로 AI에게 요청하면서 단계별로 완성한다.

**1단계 요청:**
```
Python으로 메모 하나를 리스트에 저장하는 add_memo(text) 함수를 만들어줘.
```

실행 확인 후 **2단계 요청:**
```
저장된 메모 전체를 번호와 함께 출력하는 show_memos() 함수를 추가해줘.
```

실행 확인 후 **3단계 요청:**
```
add_memo와 show_memos를 while 루프로 연결해서
사용자가 "quit"을 입력할 때까지 계속 메모를 추가할 수 있게 해줘.
```

### 실습 2. AI가 준 코드 설명 요청하기

1단계에서 받은 코드를 AI에게 다시 보내며:

```
이 코드를 한 줄씩 설명해줘. 초보자가 이해할 수 있는 수준으로.
```

설명을 읽고 이해했는지 확인한다.

### 실습 3. 의도적으로 오류 만들고 물어보기

```python
add_memo(123)  # 숫자를 넣으면 어떻게 될까?
```

실행해서 오류를 보고 AI에게 원인을 물어본다.

## 자주 하는 실수

| 실수 | 결과 | 해결 방법 |
|------|------|----------|
| 큰 기능을 한 번에 요청 | 이해 못 하는 긴 코드 | 단계별로 쪼개서 요청 |
| AI 코드를 읽지 않고 실행 | 오류 원인 찾기 어려움 | 한 줄씩 읽고 이해 후 실행 |
| 오류 없이 실행된다고 완성 | 결과가 틀릴 수 있음 | 실제 값 출력하며 결과 확인 |
| AI에게 "고쳐줘"만 반복 | 코드 이해 없이 진행 | 고친 이유를 AI에게 설명 요청 |

## 확인 체크리스트

- [ ] AI에게 요청하기 전에 기능을 작은 단위로 나눌 수 있는가
- [ ] AI가 준 코드를 읽고 각 줄이 무엇을 하는지 설명할 수 있는가
- [ ] 코드를 실행해서 원하는 결과가 나오는지 직접 확인하는가
- [ ] 오류가 났을 때 오류 메시지를 AI에게 붙여넣고 도움을 요청할 수 있는가
- [ ] 단계별로 기능을 추가하며 전체 프로그램을 완성할 수 있는가
