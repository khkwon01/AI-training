# ai-train Vibe Coding Workbook Page 01

## 목표

아주 작은 요청을 AI에게 하고, 결과를 읽고, 다시 설명을 요청하는 흐름을 직접 따라 해 본다.

## 따라 하기 순서

### 1단계. 작은 요청 정하기

좋은 예:

```text
초보자를 위해 숫자 두 개를 더하는 Python 함수를 만들어줘.
코드는 짧게 쓰고, 줄마다 쉬운 설명을 붙여줘.
```

### 2단계. AI 결과 읽기

아래를 확인한다.

- 함수 이름이 이해되는가
- 입력과 출력이 분명한가
- 설명과 코드가 맞는가

### 3단계. 다시 설명 요청하기

예:

```text
이 코드에서 초보자가 헷갈릴 수 있는 부분을 더 쉽게 설명해줘.
```

### 4단계. 한 줄 수정 포인트 적기

```text
내가 다시 확인해야 할 부분:
________________________________
```

## 좋은 요청 vs 위험한 요청

### 좋은 요청

```text
숫자 두 개를 더하는 아주 짧은 Python 함수 1개만 만들어줘.
```

### 위험한 요청

```text
내가 원하는 앱 전체를 다 만들어줘.
```

왜 위험한가:

- 범위가 너무 크다
- 이해하지 못한 코드가 많아진다
- 검토를 빼먹기 쉽다

## 확인 체크리스트

- 작은 요청부터 시작했는가
- 결과를 읽고 이해 안 되는 줄을 찾았는가
- 다시 설명을 요청했는가
- 바로 복사하지 않고 검토했는가
