## Part 1 — AI에게 첫 요청: 작은 함수 만들기

### 1-1. 좋은 요청이란?

AI에게 요청할 때 아래 세 가지를 포함하면 훨씬 좋은 결과가 나옵니다.

| 요소 | 예시 |
|------|------|
| 무엇을 만들지 | "숫자 두 개를 더하는 Python 함수" |
| 누구를 위한 것인지 | "초보자를 위해" |
| 어떤 형태로 받고 싶은지 | "코드는 짧게, 줄마다 한국어 설명 포함" |

### 1-2. 좋은 요청 vs 위험한 요청

**좋은 요청 예시:**
```text
초보자를 위해 숫자 두 개를 더하는 Python 함수를 1개만 만들어줘.
코드는 10줄 이내로 짧게 쓰고, 각 줄에 한국어 주석을 달아줘.
```

**위험한 요청 예시:**
```text
메모 앱 전체를 만들어줘. 저장, 삭제, 검색, 로그인까지 다 포함해서.
```

위험한 요청이 왜 문제인지 빈칸을 채워 보세요.

```text
범위가 너무 크면:
1. 이해하지 못한 코드가 __________________ 진다.
2. 어느 부분에서 문제가 생겼는지 __________________ 어렵다.
3. AI가 만든 코드를 내가 __________________ 하기 어렵다.
```

> 정답 힌트: "많아", "찾기", "설명"

### 1-3. 직접 요청 만들어보기

아래 빈칸에 나만의 첫 번째 요청을 작성해 보세요.

```text

기능: ________________________________ 하는 Python 함수 1개

```

**추천 연습 주제 (하나를 골라 보세요):**

- [ ] 숫자 두 개를 더하는 함수
- [ ] 이름을 입력받아 "안녕하세요, [이름]님!" 출력하는 함수
- [ ] 숫자가 짝수인지 홀수인지 알려주는 함수
- [ ] 리스트에서 가장 큰 숫자를 찾는 함수

## Part 2 — 받은 코드 검토: 이해 안 되는 부분 찾기

### 2-1. 코드를 읽을 때 확인할 체크리스트

AI가 준 코드를 바로 실행하기 전에 아래 항목을 하나씩 확인하세요.

**기본 확인:**
- [ ] 함수 이름이 이해되는가? 무슨 일을 하는 함수인지 이름만 봐도 알 수 있는가?
- [ ] 입력(매개변수)이 무엇인지 이해되는가?
- [ ] 출력(return 값)이 무엇인지 이해되는가?
- [ ] 각 줄의 설명(주석)이 코드와 맞는가?
- [ ] 이해가 안 되는 줄이 있는가? (있다면 줄 번호를 적어두자)

**심화 확인:**
- [ ] 이 코드가 내가 요청한 것과 같은 일을 하는가?
- [ ] 코드가 지나치게 복잡하지 않은가?
- [ ] 불필요한 내용이 포함되어 있지 않은가?

### 2-2. 코드 읽기 실습

아래는 AI가 만들어 줄 수 있는 예시 코드입니다. 직접 읽어보고 체크리스트를 작성해 보세요.

```python
# 숫자 두 개를 더하는 함수
def add_numbers(a, b):
    # a와 b를 더한 결과를 result에 저장
    result = a + b
    # 결과를 돌려줌
    return result

# 함수 사용 예시
answer = add_numbers(3, 5)
print(answer)  # 8이 출력됨
```

이 코드를 읽고 아래를 채워보세요.

```text
함수 이름: ________________________________
입력(매개변수): ________________________________
출력(return): ________________________________
이해 안 되는 줄 번호: ________________________________
궁금한 점: ________________________________
```

### 2-3. 이해 안 되는 부분을 AI에게 묻는 방법

이해가 안 되는 줄이 있으면, 바로 AI에게 물어보세요.  
아래 문장 패턴을 활용하면 좋습니다.

**패턴 1 — 특정 줄 설명 요청:**
```text
위 코드에서 "result = a + b" 부분이 이해가 안 돼.
초보자가 이해할 수 있게 한 줄로 설명해줘.
```

**패턴 2 — 단어 뜻 질문:**
```text
Python에서 "return"이 뭔지 초보자가 이해할 수 있게 설명해줘.
예시도 1개만 보여줘.
```

**패턴 3 — 다른 방식으로 설명 요청:**
```text
이 코드를 실생활 예시로 설명해줘.
예를 들어 "계산기"로 비유해서 설명해줘.
```

### 2-4. 직접 질문 만들어보기

### 2-5. 코드 이해도 자가 점검

아래 중 현재 나의 상태를 골라보세요.

- [ ] A: 한 줄도 설명하지 못하겠다 → AI에게 "전체를 쉽게 다시 설명해줘" 요청

## Part 3 — 코드 실행 + 오류 대응

### 3-1. 코드 실행 방법

**방법 1 — 터미널에서 실행:**

1. 코드를 `my_function.py` 파일로 저장
2. 터미널을 열고 파일이 있는 폴더로 이동
3. 아래 명령어 실행:

```bash
python my_function.py
# 또는
python3 my_function.py
```

**방법 2 — 온라인 실행 (설치 없이):**

- [repl.it](https://replit.com) 접속 → Python 선택 → 코드 붙여넣기 → Run 클릭
- [pythontutor.com](https://pythontutor.com) → 코드를 한 줄씩 실행해 볼 수 있음

**방법 3 — VS Code에서 실행:**

1. VS Code에서 `.py` 파일 열기
2. 우측 상단 ▶ 버튼 클릭
3. 또는 터미널 탭 → `python 파일이름.py` 입력

### 3-2. 오류 메시지 종류 알아보기

| 오류 이름 | 의미 | 예시 상황 |
|-----------|------|-----------|
| `SyntaxError` | 문법이 틀렸을 때 | 괄호를 닫지 않았을 때 |
| `NameError` | 없는 변수나 함수 이름을 썼을 때 | __________________ |
| `TypeError` | 잘못된 타입으로 연산했을 때 | 숫자와 글자를 더하려 할 때 |
| `IndentationError` | 들여쓰기가 틀렸을 때 | __________________ |
| `ZeroDivisionError` | 0으로 나눴을 때 | __________________ |

> 정답 힌트: "오타로 없는 변수 이름 사용", "if 블록 안에서 들여쓰기 빠뜨림", "10 / 0"

### 3-3. 오류를 AI에게 전달하는 방법

오류가 났을 때 AI에게 무작정 "오류 났어요"라고 하면 도움받기 어렵습니다.

```

## Part 4 — 기능 확장: 한 번에 하나씩 추가하기

### 4-1. 왜 한 번에 하나씩인가?

```

> 정답 힌트: "찾기", "길어", "늘어", "시간"

### 4-2. 기능 확장 패턴 (단계적 추가)

아래는 "숫자 더하기 함수"를 단계적으로 발전시키는 예시입니다.

**1단계 — 기본 기능:**
```text
요청: 숫자 두 개를 더하는 함수를 만들어줘.
```

**2단계 — 기능 하나 추가:**
```text
요청: 위 함수에서, 결과를 출력할 때 "두 숫자의 합은 [숫자]입니다"라고 
      문장으로 출력하게 바꿔줘.
```

**3단계 — 또 하나 추가:**
```text
요청: 위 함수에서, 입력값이 숫자가 아닐 경우 
      "숫자만 입력해 주세요"라고 안내하는 기능을 추가해줘.
```

각 단계마다 코드를 실행하고 이해한 뒤 다음 단계로 이동합니다.
