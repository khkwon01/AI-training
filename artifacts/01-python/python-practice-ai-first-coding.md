## 이 장에서 배우는 것

- AI에게 Python 코드를 요청하는 방법을 배운다
- AI가 준 코드를 읽고 직접 실행해본다
- 에러 메시지가 나왔을 때 AI에게 다시 물어보는 흐름을 익힌다
- "AI와 함께 코딩하는 첫 번째 루프"를 경험한다

---

## 먼저 쉬운 설명

Python 기초를 배웠다고 해서 바로 혼자 모든 것을 만들 수 있는 건 아니에요.
괜찮아요 — 실제로 일하는 개발자들도 AI에게 코드를 먼저 물어봅니다.

중요한 건 **AI가 준 코드를 그냥 복붙하는 것**이 아니라,
**읽고, 이해하고, 고쳐보는 것**이에요.

그 첫 번째 루프를 지금 경험해봅시다.

---

## 1. AI에게 코드를 요청하는 방법

AI에게 막연하게 "코드 짜줘"라고 하면 엉뚱한 결과가 나올 수 있어요.
**구체적으로** 요청할수록 원하는 코드를 받을 수 있습니다.

### 실제 프롬프트 예시 5가지

**예시 1 — 변수와 출력 활용**
```
Python으로 이름, 나이, 직업을 변수에 저장하고
"안녕하세요, 저는 [이름]이고 [나이]살입니다. 직업은 [직업]입니다." 라고
출력하는 코드를 짜줘. 초보자도 이해할 수 있게 주석도 달아줘.
```

**예시 2 — 조건문 활용**
```
Python으로 점수(score)를 입력받아서
90점 이상이면 "A학점", 80점 이상이면 "B학점",
그 이하면 "C학점"을 출력하는 코드를 짜줘.
```

**예시 3 — 리스트와 반복문 활용**
```
Python 리스트에 과일 이름 5개를 넣고,
for문으로 하나씩 출력하는 코드를 짜줘.
각 줄에 번호도 같이 출력해줘. (예: 1. 사과)
```

**예시 4 — 함수 만들기**
```
Python으로 두 숫자를 입력받아서 사칙연산(+, -, *, /) 결과를 모두 출력하는
함수를 만들어줘. 함수 이름은 calculate로 해줘.
나눗셈에서 0으로 나누는 경우도 처리해줘.
```

**예시 5 — 딕셔너리 활용**
```
Python 딕셔너리에 학생 3명의 이름과 점수를 저장하고,
점수가 가장 높은 학생의 이름과 점수를 출력하는 코드를 짜줘.
딕셔너리 형태: {"이름": 점수}
```

### 좋은 프롬프트의 공통점

막연한 요청과 구체적인 요청을 비교해 보면:

| 막연한 요청 | 구체적인 요청 |
|------------|-------------|
| "코드 짜줘" | "Python으로 리스트 평균 구하는 코드 짜줘" |
| "에러 고쳐줘" | "아래 코드에서 TypeError가 나는데 왜 그런지 설명하고 고쳐줘" |
| "더 좋게 만들어줘" | "변수명을 더 명확하게 바꾸고, 함수에 주석을 추가해줘" |

## 2. AI가 준 코드 읽고 실행하기

AI가 아래와 같은 코드를 줬다고 해봅시다.

```python
# 과일 목록 출력 프로그램
fruits = ["사과", "바나나", "딸기", "포도", "수박"]

for i, fruit in enumerate(fruits, start=1):
    print(f"{i}. {fruit}")
```

**코드를 받았을 때 해야 할 3단계:**

1. **눈으로 읽기** — `enumerate`가 뭔지 몰라도 괜찮아요. 일단 흐름을 파악해요.
2. **파일로 저장하기** — `fruits.py`라는 이름으로 저장합니다.
3. **실행해보기**

```bash
python fruits.py
```

**출력 결과:**
```
1. 사과
2. 바나나
3. 딸기
4. 포도
5. 수박
```

모르는 부분이 있으면 AI에게 바로 물어보세요:
```
위 코드에서 enumerate가 뭐야? 쉽게 설명해줘.
```

## 3. 에러 발생 → AI에게 전달 → 수정하기

코딩하다 보면 에러는 반드시 만납니다. 에러를 무서워하지 마세요.
**에러 메시지를 그대로 AI에게 붙여넣는 것**이 가장 빠른 해결책이에요.

예를 들어, 코드를 이렇게 잘못 입력했다면:

```python
fruits = ["사과", "바나나", "딸기"
for fruit in fruits:
    print(fruit)
```

터미널에 이런 에러가 납니다:

```
  File "fruits.py", line 2
    for fruit in fruits:
      ^
SyntaxError: '[' was never closed
```

이때 AI에게 이렇게 전달하세요:

```
내 Python 코드에서 이런 에러가 났어. 뭐가 문제야?

--- 코드 ---
fruits = ["사과", "바나나", "딸기"
for fruit in fruits:
    print(fruit)

--- 에러 ---
SyntaxError: '[' was never closed
```

AI가 1번 줄에서 `]`를 빠뜨렸다고 알려줄 거예요.
이렇게 **에러 코드 + 에러 메시지를 함께** 주는 습관이 중요합니다.

## AI가 준 코드에서 자주 보이는 3가지 문제

AI가 코드를 줄 때 항상 완벽한 건 아니에요.
특히 초보자에게 자주 보이는 3가지 패턴을 알아두면, AI 코드를 더 잘 읽을 수 있어요.

### 문제 1: 불필요한 복잡성

AI는 종종 간단한 문제를 복잡하게 풀기도 합니다.

**AI가 준 코드 (복잡):**
```python
# 리스트에서 짝수만 골라내기
numbers = [1, 2, 3, 4, 5, 6]
even_numbers = []
for i in range(len(numbers)):
    if numbers[i] % 2 == 0:
        even_numbers.append(numbers[i])
print(even_numbers)
```

**더 간단한 코드:**
```python
numbers = [1, 2, 3, 4, 5, 6]
even_numbers = [n for n in numbers if n % 2 == 0]
print(even_numbers)
```

AI에게 "더 간단하게 바꿀 수 있어?"라고 물어보는 습관을 들이세요.

---

### 문제 2: 구버전 문법

Python은 버전이 올라갈수록 더 편리한 문법이 생겨납니다.
AI가 가끔 오래된 스타일의 코드를 줄 수 있어요.

**구버전 방식:**
```python
# 문자열 포맷팅 — 옛날 방식
name = "철수"
age = 20
print("안녕하세요, %s입니다. 나이는 %d살입니다." % (name, age))
print("안녕하세요, {}입니다. 나이는 {}살입니다.".format(name, age))
```

**현재 권장 방식 (Python 3.6+):**
```python
# f-string 사용
name = "철수"
age = 20
print(f"안녕하세요, {name}입니다. 나이는 {age}살입니다.")
```

AI에게 "Python 3.10 이상 버전 기준으로 최신 문법을 써줘"라고 명시하면 더 현대적인 코드를 받을 수 있어요.

---

### 문제 3: 변수명 문제

AI가 예제 코드를 빠르게 만들 때 의미 없는 변수명을 쓰는 경우가 있어요.

**변수명이 불명확한 코드:**
```python
def calc(d, n):
    r = 0
    for i in d:
        r += i
    return r / n
```

**변수명이 명확한 코드:**
```python
def calculate_average(scores, count):
    total = 0
    for score in scores:
        total += score
    return total / count
```

코드를 받았을 때 변수명이 한 글자이거나 의미 없는 이름이라면, AI에게 이렇게 요청하세요:
```
이 코드에서 변수명과 함수명을 더 명확하게 바꿔줘.
이름만 봐도 역할을 알 수 있어야 해.
```

## 에러를 AI에게 전달할 때 좋은 형식 vs 나쁜 형식

에러를 어떻게 전달하느냐에 따라 AI의 답변 품질이 크게 달라집니다.

### 나쁜 형식

```
에러 났어. 고쳐줘.
```

```
코드 실행하니까 안 돼.
```

```
TypeError 났는데 뭐가 문제야?
```

이런 요청은 AI가 맥락을 전혀 알 수 없어서 일반적인 답만 줍니다.

---

### 좋은 형식

```
Python 코드에서 에러가 났어. 원인을 설명하고 고쳐줘.

--- 코드 ---
score = input("점수를 입력하세요: ")
if score >= 90:
    print("A학점")

--- 에러 메시지 ---
Traceback (most recent call last):
  File "grade.py", line 2, in <module>
    if score >= 90:
TypeError: '>=' not supported between instances of 'str' and 'int'

--- 실행 환경 ---
Python 3.11, macOS

--- 내가 시도한 것 ---
아직 아무것도 시도하지 않았음
```

---

### 좋은 형식의 4가지 요소

| 요소 | 포함 이유 |
|------|-----------|
| 코드 전체 | AI가 문맥을 파악할 수 있음 |
| 에러 메시지 전체 | 에러 유형과 위치를 정확히 전달 |
| 실행 환경 (Python 버전, OS) | 버전에 따라 해결 방법이 다를 수 있음 |
| 내가 시도한 것 | AI가 이미 해본 방법을 반복하지 않음 |

### 실습 3 — 에러 나는 코드를 AI와 함께 고치기

이번 실습은 처음부터 에러가 있는 코드를 주고, AI와 함께 단계적으로 고쳐나가는 연습입니다.

**1단계: 아래 코드를 `buggy.py`로 저장하고 실행하세요.**

```python
def calculate_total(items):
    total = 0
    for item in items
        total = total + item["price"]
    return total

shopping_cart = [
    {"name": "사과", "price": 1500},
    {"name": "바나나", "price": 800},
    {"name": "딸기", "price": 3000}
]

result = calculate_total(shopping_cart)
print("총 금액: " + result + "원")
```

**2단계: 에러 메시지를 확인하세요.**

첫 번째 에러가 나면, 그 에러만 먼저 AI에게 전달하세요.
한 번에 모든 에러를 해결하려 하지 말고, **에러를 하나씩** 해결하는 연습을 합니다.

**3단계: AI에게 첫 번째 에러를 전달하세요.**

```
Python 코드에서 에러가 났어. 이 에러 하나만 먼저 고쳐줘.

--- 코드 ---
[buggy.py 전체 붙여넣기]

--- 에러 ---
[터미널에서 나온 에러 메시지 붙여넣기]
```

**4단계: 고친 코드를 실행하고, 다음 에러가 나면 같은 방식으로 반복하세요.**

이 코드에는 총 2개의 버그가 숨어있습니다:
- `SyntaxError`: `for item in items` 뒤에 `:` 누락
- `TypeError`: `print("총 금액: " + result + "원")` — 숫자를 문자열과 직접 합칠 수 없음

모든 에러를 고쳐서 아래 출력이 나오면 성공입니다:
```

```

**5단계: 마지막으로 AI에게 이렇게 요청하세요.**

```
이 코드에서 변수명이나 가독성을 더 개선할 부분이 있어?
```

AI의 제안을 읽고, 반영할지 말지 직접 판단해보세요.

## AI와 코딩할 때 "멈춰서 이해하기" 습관 만들기

AI가 코드를 빠르게 줄수록, 그냥 복붙하고 싶은 유혹이 생깁니다.
하지만 이해 없이 복붙만 하면 조금만 달라져도 혼자 해결하지 못하게 돼요.

**"멈춰서 이해하기"는 AI 코드를 받은 직후 30초간 하는 루틴입니다.**

### 4단계 이해 루틴

**1단계 — 전체 흐름 파악 (10초)**

코드를 처음부터 끝까지 훑으면서 스스로에게 물어보세요:
- "이 코드는 뭘 하는 코드야?"
- "입력은 뭐고, 출력은 뭐야?"

---

**2단계 — 모르는 키워드 찾기 (10초)**

모르는 단어에 밑줄을 긋거나 메모하세요.
예: `enumerate`, `f-string`, `with`, `try/except`

모르는 게 있어도 당장 코드가 실행되면 일단 다음으로 넘어가도 괜찮아요.
나중에 AI에게 하나씩 물어보면 됩니다.

---

**3단계 — 실행 전 예측 (5초)**

실행하기 전에 "이 코드를 실행하면 어떤 결과가 나올까?"를 먼저 생각해보세요.
예측이 맞으면 이해한 것이고, 틀리면 왜 다른지 AI에게 물어보세요.

---

**4단계 — 한 줄 요약 (5초)**

코드를 한 문장으로 설명할 수 있으면 이해한 겁니다.
예: "이 코드는 리스트에서 18세 이상인 사람의 이름만 모아서 출력한다."

설명하지 못한다면, AI에게 이렇게 물어보세요:
```
이 코드를 초등학생도 이해할 수 있게 한 문장으로 설명해줘.
```

---

### 이해 없이 복붙할 때 생기는 일

| 상황 | 이해 없이 복붙 | 이해하고 사용 |
|------|--------------|-------------|
| 에러가 났을 때 | 어디서 문제가 생겼는지 모름 | 에러 위치를 빠르게 찾을 수 있음 |
| 요구사항이 바뀔 때 | 코드 전체를 AI에게 다시 맡김 | 관련 부분만 수정 가능 |
| 코드 리뷰 받을 때 | 왜 이렇게 짰는지 설명 못함 | 설계 의도를 설명할 수 있음 |
| 비슷한 문제를 만날 때 | 같은 패턴인지 인식 못함 | "아, 저번에 이런 거 했지" 하고 적용 가능 |

**목표:** AI의 코드를 이해하고 쓰는 것. AI는 도구이지, 뇌를 대신하는 것이 아닙니다.

## 자주 하는 실수

| 실수 | 에러 메시지 | 해결 방법 |
|------|------------|----------|
| 괄호나 따옴표를 안 닫음 | `SyntaxError: '(' was never closed` | 열린 기호와 닫힌 기호 개수를 맞춘다 |
| `input()`을 숫자 비교에 바로 사용 | `TypeError: '>=' not supported between instances of 'str' and 'int'` | `int(input(...))` 으로 변환한다 |
| 들여쓰기가 잘못됨 | `IndentationError: expected an indented block` | if/for 다음 줄은 반드시 4칸 들여쓰기 |
| 파일명과 실행 명령어가 다름 | `python: can't open file 'grade.py'` | 파일을 저장한 폴더에서 실행했는지 확인 |
| AI 코드를 그대로 복붙했는데 작동 안 함 | 다양한 에러 | 코드 앞뒤에 설명 텍스트가 섞였는지 확인 |

## 확인 체크리스트

- [ ] AI에게 구체적인 프롬프트로 코드를 요청해봤다
- [ ] AI가 준 코드를 `.py` 파일로 저장하고 실행했다
- [ ] `enumerate`, `f-string` 등 모르는 부분을 AI에게 다시 물어봤다
- [ ] 에러 메시지를 코드와 함께 AI에게 전달해봤다
- [ ] 에러 원인을 AI 설명을 읽고 직접 고쳐봤다
- [ ] 에러 나는 코드를 AI와 단계적으로 고쳐봤다 (실습 3)
- [ ] AI가 준 코드를 받은 직후 "멈춰서 이해하기" 루틴을 한 번 실행해봤다
- [ ] 나만의 프롬프트를 작성해서 미니 프로그램을 만들어봤다
