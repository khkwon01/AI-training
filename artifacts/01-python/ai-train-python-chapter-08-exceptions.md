## 이 장에서 배우는 것

- 예외가 무엇인지
- `try`와 `except`를 왜 쓰는지
- 초보자가 자주 만나는 오류 상황을 어떻게 처리하는지

## 먼저 쉬운 설명

프로그램을 실행하다 보면 예상하지 못한 문제가 생길 수 있다.

예를 들어:

- 숫자를 입력해야 하는데 문자를 넣었을 때
- 파일이 없을 때
- 0으로 나누려고 할 때

이런 상황에서 프로그램이 바로 멈추지 않고,
조금 더 친절하게 대응하도록 만드는 방법이 예외처리다.

## 1. 예외란 무엇인가

예외는 프로그램 실행 중 생기는 문제 상황이라고 생각하면 쉽다.

## 2. `try`와 `except`

```python
try:
    number = int(input("숫자를 입력하세요: "))
    print(number)
except:
    print("숫자로 입력해 주세요.")
```

이 코드는 오류가 나더라도 프로그램이 바로 멈추는 대신 안내 문장을 보여 준다.

## 3. 왜 예외처리가 필요할까

- 초보자가 실수해도 프로그램이 너무 쉽게 멈추지 않게 하기 위해
- 사용자에게 더 쉬운 안내를 주기 위해
- 어떤 문제가 생길 수 있는지 미리 생각하는 연습을 하기 위해

## 4. 쉬운 예시 1: 숫자 입력

```python
try:
    age = int(input("나이를 입력하세요: "))
    print("입력한 나이:", age)
except ValueError:
    print("숫자만 입력해 주세요.")
```

## 5. 쉬운 예시 2: 0으로 나누기

```python
try:
    result = 10 / 0
    print(result)
except ZeroDivisionError:
    print("0으로 나눌 수 없습니다.")
```

## 6. 쉬운 예시 3: 파일 읽기

```python
try:
    with open("missing.txt", "r", encoding="utf-8") as file:
        print(file.read())
except FileNotFoundError:
    print("파일을 찾을 수 없습니다.")
```

## 7. 따라 하기 실습

### 실습 1. 숫자 입력받기

사용자가 숫자가 아닌 값을 넣었을 때도 안내 문장이 나오도록 만들어 보자.

### 실습 2. 파일 읽기

없는 파일을 읽으려고 할 때 친절한 메시지를 보여 주도록 만들어 보자.

## 교사용 메모

- 강조: 예외는 "실패"보다 "친절한 안내를 만들 기회"로 설명한다.
- 막힘: `except`를 너무 넓게 쓰거나, 오류 이름과 상황을 연결하지 못하는 경우가 많다.
- 질문 1: `"hello"`를 숫자로 바꾸려 하면 어떤 일이 생길까?
- 질문 2: 파일이 없을 때 어떤 문장을 보여 주면 좋을까?

## 자주 하는 실수

- `try`만 쓰고 `except`를 쓰지 않기
- 모든 오류를 한꺼번에 막연하게 처리하기
- 오류 메시지를 너무 어렵게 쓰기

## 확인 체크리스트

- 예외가 무엇인지 설명할 수 있는가
- `try`와 `except`를 쓸 수 있는가
- 숫자 입력 오류를 처리할 수 있는가
- 파일이 없을 때 안내 문장을 보여 줄 수 있는가
