## 1. 변수와 자료형 확인 (Chapter 01-02)

**핵심 질문:** 아래 코드를 보고 각 변수의 자료형을 말할 수 있나요?

```python
# quick_check_01.py

이름 = "김민준"
나이 = 17
키 = 172.5
재학중 = True

print(type(이름))    # <class 'str'>
print(type(나이))    # <class 'int'>
print(type(키))      # <class 'float'>
print(type(재학중))  # <class 'bool'>
```

**빠른 채점 포인트 (교사용):**
- `"김민준"` → `str` (따옴표가 있으면 문자열)
- `17` → `int` (소수점 없는 숫자)
- `172.5` → `float` (소수점 있는 숫자)
- `True` / `False` → `bool` (반드시 대문자로 시작)

---

**자료형 변환 확인:**

```python
# 문자열로 입력받은 숫자를 계산에 쓰려면?
입력값 = input("점수를 입력하세요: ")  # 입력: "95"
점수 = int(입력값)                      # 문자열 → 정수 변환
print(점수 + 5)                         # 100
```

## 2. 문자열 다루기 확인 (Chapter 02)

**핵심 질문:** 아래 코드의 출력 결과를 예측할 수 있나요?

```python
# quick_check_02.py

학교 = "서울중학교"
학년 = 2
반 = 3

# f-string 방식
소개 = f"저는 {학교} {학년}학년 {반}반입니다."
print(소개)
# 출력: 저는 서울중학교 2학년 3반입니다.

# 문자열 길이
print(len(학교))   # 5
print(학교[0])     # 서  (첫 번째 글자, 인덱스는 0부터 시작)
print(학교[-1])    # 교  (마지막 글자)
```

**빠른 채점 포인트 (교사용):**
- f-string: `f"..."` 안에서 `{변수명}` 으로 값 삽입
- `len()`: 문자 개수 반환
- 인덱스 `[0]`: 첫 번째, `[-1]`: 마지막

## 3. 조건문 확인 (Chapter 03)

**핵심 질문:** 아래 코드가 어떤 결과를 출력하는지, 그리고 왜 그런지 설명할 수 있나요?

```python
# quick_check_03.py

점수 = 78

if 점수 >= 90:
    print("A등급")
elif 점수 >= 80:
    print("B등급")
elif 점수 >= 70:
    print("C등급")
else:
    print("D등급")

# 출력: C등급
```

**실행 흐름 추적:**

```
점수 = 78
78 >= 90 ?  → False  → 다음 조건으로
78 >= 80 ?  → False  → 다음 조건으로
78 >= 70 ?  → True   → "C등급" 출력, 종료
```

**빠른 채점 포인트 (교사용):**
- `if` / `elif` / `else` 순서와 역할을 구분할 수 있는가
- 조건이 `True`가 되는 순간 해당 블록만 실행하고 나머지는 건너뜀
- 들여쓰기(indent)가 블록을 결정함

## 4. 반복문 확인 (Chapter 04)

**핵심 질문:** `for` 반복문과 `while` 반복문의 차이를 코드로 설명할 수 있나요?

```python
# quick_check_04.py

# for 반복문: 횟수가 정해져 있을 때
과목들 = ["수학", "영어", "과학"]
for 과목 in 과목들:
    print(f"{과목} 공부 완료!")

# 출력:
# 수학 공부 완료!
# 영어 공부 완료!
# 과학 공부 완료!
```

```python
# while 반복문: 조건이 만족될 때까지 반복
남은_문제 = 5
while 남은_문제 > 0:
    print(f"문제 {남은_문제}번 풀기")
    남은_문제 -= 1  # 남은_문제 = 남은_문제 - 1

# 출력:
# 문제 5번 풀기
# 문제 4번 풀기
# 문제 3번 풀기
# 문제 2번 풀기
# 문제 1번 풀기
```

**빠른 채점 포인트 (교사용):**
- `for`: 리스트나 범위처럼 **순서가 있는 것**을 순서대로 처리
- `while`: 조건이 `True`인 동안 반복, 조건이 `False`가 되면 종료
- `range(5)`: 0, 1, 2, 3, 4 — 5가 아닌 0부터 시작함을 주의

## 자주 하는 실수

| 실수 유형 | 잘못된 코드 | 오류 메시지 | 올바른 코드 |
|---|---|---|---|
| 들여쓰기 없음 | `if x > 0:` 다음 줄에 들여쓰기 없음 | `IndentationError: expected an indented block` | `if x > 0:` 다음 줄에 스페이스 4칸 |
| 문자열과 숫자 더하기 | `"나이: " + 17` | `TypeError: can only concatenate str (not "int") to str` | `"나이: " + str(17)` 또는 f-string 사용 |
| input() 결과를 그대로 계산 | `점수 = input(...)` → `점수 + 10` | `TypeError: can only concatenate str (not "int") to str` | `점수 = int(input(...))` |
| = 와 == 혼동 | `if 점수 = 100:` | `SyntaxError: invalid syntax` | `if 점수 == 100:` |
| range() 끝 숫자 포함 착각 | `range(1, 5)` → 1,2,3,4,5 기대 | (오류 없이 잘못된 결과) | `range(1, 6)` 으로 수정 |
| True/False 소문자 | `재학중 = true` | `NameError: name 'true' is not defined` | `재학중 = True` (대문자) |
| while 무한 루프 | `while True:` 안에서 조건 변화 없음 | 프로그램이 멈추지 않음 | 루프 안에서 카운터 또는 조건값 변경 |
