## 이 장에서 배우는 것

- Python의 기본 자료형(문자열, 숫자, 리스트, 딕셔너리)을 이해한다
- 변수를 선언하고 값을 저장하는 방법을 익힌다
- 조건문과 반복문의 기본 패턴을 파악한다
- 함수를 정의하고 호출하는 방법을 배운다
- 자주 쓰는 내장 함수와 메서드를 바로 찾아 쓸 수 있다
- 치트시트를 보며 스스로 코드를 작성할 수 있게 된다

## 먼저 쉬운 설명

Python은 영어와 비슷한 문법 덕분에 처음 프로그래밍을 배우는 사람에게 가장 인기 있는 언어입니다.

하지만 막상 코딩을 시작하면 "변수를 어떻게 만들었지?", "리스트에서 마지막 요소를 꺼내는 게 뭐였지?" 같은 질문이 수도 없이 생깁니다. 책을 처음부터 다시 펼치기엔 너무 번거롭죠.

**치트시트(Quick Reference)**는 자주 쓰는 문법을 한 장에 모아 놓은 참고표입니다. 이 장을 읽고 나면, 코딩 중에 막힐 때마다 이 페이지만 열어도 대부분의 문제를 해결할 수 있게 됩니다.

## 1. 변수와 자료형

Python은 변수 타입을 따로 선언하지 않아도 됩니다. 값을 넣으면 Python이 알아서 타입을 정합니다.

```python
# 기본 자료형 예시 (my_profile.py)

이름 = "김민준"          # str  (문자열)
나이 = 28               # int  (정수)
키   = 175.5            # float (소수)
취업_완료 = True         # bool (참/거짓)

# 타입 확인
print(type(이름))        # <class 'str'>
print(type(나이))        # <class 'int'>

# 타입 변환
나이_문자열 = str(나이)   # "28"
점수_정수   = int("95")  # 95
점수_소수   = float("9.5")  # 9.5
```

| 자료형 | 예시 | 설명 |
|--------|------|------|
| `str` | `"안녕"` | 따옴표로 감싼 텍스트 |
| `int` | `42` | 소수점 없는 숫자 |
| `float` | `3.14` | 소수점 있는 숫자 |
| `bool` | `True` / `False` | 참 또는 거짓 |

## 2. 문자열 다루기

```python
# string_practice.py

메시지 = "안녕하세요, Python!"

# 자주 쓰는 문자열 메서드
print(len(메시지))              # 길이: 18
print(메시지.upper())           # 대문자: 안녕하세요, PYTHON!
print(메시지.replace("Python", "세상"))  # 안녕하세요, 세상!
print(메시지.split(","))        # ['안녕하세요', ' Python!']
print("  공백제거  ".strip())   # '공백제거'
print(메시지.startswith("안녕")) # True

# f-문자열 (가장 많이 씀)
이름 = "지수"
나이 = 22
소개 = f"제 이름은 {이름}이고, {나이}살입니다."
print(소개)  # 제 이름은 지수이고, 22살입니다.

# 문자열 인덱싱
단어 = "Python"
print(단어[0])   # P  (첫 번째)
print(단어[-1])  # n  (마지막)
print(단어[0:3]) # Pyt (슬라이싱)
```

## 3. 리스트(List)

순서가 있는 값의 묶음입니다. 같은 종류의 데이터를 여러 개 다룰 때 씁니다.

```python
# list_practice.py

과목 = ["수학", "영어", "과학", "국어"]

# 접근
print(과목[0])    # 수학
print(과목[-1])   # 국어

# 추가 / 삭제
과목.append("체육")       # 끝에 추가
과목.insert(1, "음악")    # 1번 위치에 삽입
과목.remove("영어")       # 값으로 삭제
마지막 = 과목.pop()       # 마지막 요소 꺼내기

# 유용한 메서드
print(len(과목))          # 개수
print(sorted(과목))       # 정렬된 새 리스트 반환
과목.sort()               # 원본 정렬
print("수학" in 과목)     # 포함 여부: True

# 리스트 슬라이싱
숫자 = [0, 1, 2, 3, 4, 5]
print(숫자[1:4])   # [1, 2, 3]
print(숫자[:3])    # [0, 1, 2]
print(숫자[3:])    # [3, 4, 5]
```

## 4. 딕셔너리(Dictionary)

키(key)와 값(value)을 짝지어 저장합니다. 이름표 붙은 서랍장이라고 생각하세요.

```python
# dict_practice.py

학생 = {
    "이름": "박서연",
    "나이": 20,
    "전공": "컴퓨터공학",
    "성적": 3.8
}

# 읽기
print(학생["이름"])              # 박서연
print(학생.get("전화", "없음"))  # 키가 없으면 기본값 반환

# 추가 / 수정 / 삭제
학생["학번"] = "20240001"       # 추가
학생["나이"] = 21               # 수정
del 학생["성적"]                # 삭제

# 순회
for 키, 값 in 학생.items():
    print(f"{키}: {값}")

# 유용한 메서드
print(학생.keys())    # 모든 키
print(학생.values())  # 모든 값
print("이름" in 학생) # 키 존재 여부: True
```

## 5. 조건문 (if / elif / else)

```python
# grade_checker.py

점수 = 85

if 점수 >= 90:
    등급 = "A"
elif 점수 >= 80:
    등급 = "B"
elif 점수 >= 70:
    등급 = "C"
else:
    등급 = "F"

print(f"점수 {점수}점 → 등급: {등급}")  # 점수 85점 → 등급: B

# 한 줄 조건문 (삼항 연산자)
결과 = "합격" if 점수 >= 60 else "불합격"
print(결과)  # 합격

# 비교 연산자 정리
# ==  같다       !=  다르다
# >   크다        <   작다
# >=  크거나 같다  <=  작거나 같다
# and 둘 다 참    or  하나라도 참    not 반대
```

## 6. 반복문 (for / while)

```python
# loop_practice.py

# for 반복문
과일 = ["사과", "바나나", "딸기"]
for 항목 in 과일:
    print(f"좋아하는 과일: {항목}")

# range() 활용
for i in range(5):          # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 6):       # 1, 2, 3, 4, 5
    print(i)

for i in range(0, 10, 2):   # 0, 2, 4, 6, 8 (2씩 증가)
    print(i)

# enumerate() - 인덱스와 값 같이 쓰기
for 순서, 과일명 in enumerate(과일, start=1):
    print(f"{순서}번째: {과일명}")

# while 반복문
카운트 = 0
while 카운트 < 3:
    print(f"현재 카운트: {카운트}")
    카운트 += 1

# break / continue
for i in range(10):
    if i == 5:
        break       # 반복 완전히 종료
    if i % 2 == 0:
        continue    # 이번 회차만 건너뜀
    print(i)        # 1, 3
```

## 7. 함수 (def)

반복되는 코드를 묶어서 이름을 붙인 것입니다.

```python
# functions.py

# 기본 함수
def 인사(이름):
    print(f"안녕하세요, {이름}님!")

인사("민수")   # 안녕하세요, 민수님!

# 반환값이 있는 함수
def 세금_계산(금액, 세율=0.1):   # 기본값 매개변수
    세금 = 금액 * 세율
    return 세금

결과 = 세금_계산(50000)         # 5000.0
결과2 = 세금_계산(50000, 0.2)   # 10000.0

# 여러 값 반환
def 최대최소(숫자_리스트):
    return max(숫자_리스트), min(숫자_리스트)

최대, 최소 = 최대최소([3, 1, 7, 2, 9])
print(f"최대: {최대}, 최소: {최소}")  # 최대: 9, 최소: 1

# 람다 함수 (한 줄 함수)
제곱 = lambda x: x ** 2
print(제곱(5))   # 25
```

## 8. 자주 쓰는 내장 함수 모음

# builtins_reference.py

숫자들 = [3, 1, 4, 1, 5, 9, 2, 6]

이름 = input("이름을 입력하세요: ")

### 실습 2 — 성적 관리 프로그램 만들기

실습 1에서 배운 입력과 조건문을 바탕으로 리스트와 반복문을 추가합니다.

```python
# grade_manager.py

과목_점수 = {
    "국어": 88,
    "수학": 72,
    "영어": 95,
    "과학": 80,
}

총점 = sum(과목_점수.values())
평균 = 총점 / len(과목_점수)

print("=== 성적표 ===")
for 과목, 점수 in 과목_점수.items():
    등급 = "A" if 점수 >= 90 else ("B" if 점수 >= 80 else "C")
    print(f"  {과목}: {점수}점 ({등급})")

print(f"\n총점: {총점}점")
print(f"평균: {평균:.1f}점")   # :.1f → 소수점 1자리
```

**확인 포인트:** `:.1f`는 f-문자열 안에서 소수점 자릿수를 지정하는 방법입니다.

### 실습 3 — 함수로 성적 관리 도구 완성하기

실습 2의 코드를 함수로 정리해 재사용 가능하게 만듭니다.

```python
# grade_tool.py

def 등급_계산(점수):
    if 점수 >= 90:
        return "A"
    elif 점수 >= 80:
        return "B"
    elif 점수 >= 70:
        return "C"
    else:
        return "F"

def 성적표_출력(이름, 점수_딕셔너리):
    print(f"\n=== {이름}의 성적표 ===")
    for 과목, 점수 in 점수_딕셔너리.items():
        print(f"  {과목}: {점수}점 → {등급_계산(점수)}")
    평균 = sum(점수_딕셔너리.values()) / len(점수_딕셔너리)
    print(f"  평균: {평균:.1f}점")

# 함수 호출
내_점수 = {"국어": 88, "수학": 72, "영어": 95}
성적표_출력("김민준", 내_점수)
```

## 자주 하는 실수

| 실수 | 에러 메시지 | 원인 | 해결 방법 |
|------|------------|------|-----------|
| 문자열과 숫자 더하기 | `TypeError: can only concatenate str (not "int") to str` | `"나이: " + 나이` 처럼 타입이 다른 값을 `+`로 연결 | `str(나이)` 로 변환하거나 f-문자열 사용 |
| 없는 딕셔너리 키 접근 | `KeyError: '전화'` | `학생["전화"]` 처럼 없는 키 직접 접근 | `학생.get("전화", "없음")` 사용 |
| 인덱스 범위 초과 | `IndexError: list index out of range` | 리스트 길이보다 큰 인덱스 접근 | `len(리스트)` 로 길이 확인 후 접근 |
| 들여쓰기 오류 | `IndentationError: expected an indented block` | if/for/def 다음 줄에 들여쓰기 없음 | 블록 안 코드는 스페이스 4칸 들여쓰기 |
| 정의 전 함수 호출 | `NameError: name '함수명' is not defined` | 함수 정의보다 호출이 먼저 나옴 | `def` 로 정의한 뒤에 호출 |
| input() 결과를 숫자로 사용 | `TypeError: '>' not supported between instances of 'str' and 'int'` | `input()` 반환값은 항상 `str` | `int(input(...))` 으로 변환 |
| 등호 하나로 비교 | `SyntaxError` 또는 의도치 않은 동작 | 조건문에 `=` 사용 (할당) | 비교는 반드시 `==` 사용 |

## 확인 체크리스트

스스로 아래 항목을 할 수 있는지 확인해 보세요.

- [ ] 변수를 선언하고 `str`, `int`, `float`, `bool` 타입을 구분할 수 있다
- [ ] `f"...{변수}..."` 형식의 f-문자열을 사용할 수 있다
- [ ] 리스트에서 `append()`, `remove()`, `pop()`, 슬라이싱을 사용할 수 있다
- [ ] 딕셔너리에서 `get()`, `.items()`, `.keys()`, `.values()`를 사용할 수 있다
- [ ] `if / elif / else` 조건문을 올바른 들여쓰기로 작성할 수 있다
- [ ] `for ... in range(...)` 와 `for ... in 리스트` 를 구별해서 쓸 수 있다
- [ ] `def` 로 함수를 정의하고 `return` 으로 값을 반환할 수 있다
- [ ] `input()` 의 반환값을 숫자로 변환할 수 있다
- [ ] `TypeError`, `KeyError`, `IndexError` 에러 메시지를 보고 원인을 찾을 수 있다
- [ ] 실습 3의 `grade_tool.py` 를 보지 않고 직접 작성할 수 있다
