## 파트 1. VS Code 처음 열기 — 화면 각 부분 이름 익히기

### VS Code 화면 구조

VS Code를 처음 켜면 다섯 개의 영역으로 나뉜 화면이 보인다.
각 영역의 이름과 역할을 먼저 기억해 두면 앞으로 설명을 들을 때 헷갈리지 않는다.

```
┌─────────────────────────────────────────────────────────────────┐
│  Menu Bar  (파일 / 편집 / 보기 / 실행 ...)                        │
├──┬──────────────────────────────────────────────────────────────┤
│  │  Side Bar              │  Editor Area                        │
│A │  (Explorer / Search /  │  (코드를 입력하는 곳)                 │
│c │   Source Control 등)   │                                     │
│t │                        │                                     │
│i │                        │                                     │
│v │                        │                                     │
│i │                        ├─────────────────────────────────────┤
│t │                        │  Terminal Panel                     │
│y │                        │  (명령을 입력하고 실행하는 곳)         │
│B │                        │                                     │
│a │                        │                                     │
│r │                        │                                     │
├──┴────────────────────────┴─────────────────────────────────────┤
│  Status Bar  (인터프리터 버전 / Git 상태 / 인코딩 ...)              │
└─────────────────────────────────────────────────────────────────┘
```

### 각 영역 설명

| 영역 이름 | 위치 | 역할 |
|-----------|------|------|
| Activity Bar | 가장 왼쪽, 좁은 세로 줄 | 아이콘을 눌러 Side Bar 내용을 바꾼다 |
| Side Bar | Activity Bar 옆 | Explorer, Search, Extensions 등의 패널이 표시된다 |
| Editor Area | 화면 중앙, 가장 넓은 곳 | 코드를 직접 입력하고 수정하는 공간이다 |
| Terminal Panel | 화면 아래쪽 | 명령을 입력하고 Python을 실행하는 곳이다 |
| Status Bar | 가장 아래, 한 줄짜리 띠 | 현재 파일 정보, Python 버전, Git 브랜치 등이 표시된다 |

### Activity Bar 아이콘 읽기

Activity Bar에는 아이콘이 세로로 나열되어 있다.
자주 쓰는 아이콘만 먼저 기억해 두자.

| 아이콘 모양 | 이름 | 열리는 패널 |
|-------------|------|-------------|
| 파일 두 장 겹친 모양 | Explorer | 폴더와 파일 목록 |
| 돋보기 모양 | Search | 파일 내 텍스트 검색 |
| Git 분기 모양 | Source Control | Git 변경 사항 |
| 퍼즐 조각 모양 | Extensions | 확장 프로그램 설치 |
| 벌레와 삼각형 모양 | Run and Debug | 디버깅 패널 |

### 직접 해보기

1. VS Code를 실행한다.
2. 각 Activity Bar 아이콘을 한 번씩 클릭해서 Side Bar 내용이 바뀌는지 확인한다.
3. Explorer 아이콘(파일 두 장 모양)을 눌러 Side Bar를 Explorer 상태로 돌려 놓는다.
4. 화면 맨 아래 Status Bar에서 Python 버전이 표시되는 자리를 찾는다.

```text
Status Bar에서 발견한 정보:
________________________________

Activity Bar에서 아이콘이 몇 개 보이는가:
________________________________
```

완료 체크: [ ] 다섯 개 영역의 이름을 보지 않고 말할 수 있다

## 파트 2. 폴더 열기와 파일 만들기

### 공부용 폴더 결정하기

VS Code는 파일 하나를 여는 것보다 **폴더 단위**로 여는 것이 훨씬 편하다.
폴더를 열면 Explorer에서 그 폴더 안의 파일을 모두 볼 수 있고,
터미널도 그 폴더 기준으로 자동으로 열린다.

권장 폴더 이름 예시:

```text
python-study/
```

폴더를 미리 만들어 두거나, VS Code에서 만들 수 있다.

직접 적어 보기:

```text
내가 사용할 폴더 이름:
________________________________

폴더를 만든 위치(경로):
________________________________
```

### 방법 A. 메뉴로 폴더 열기

1. 상단 메뉴에서 `File` 을 클릭한다.
2. `Open Folder...` 를 클릭한다. (Mac은 `Open...`)
3. 창이 열리면 공부용 폴더를 선택하고 `열기` 버튼을 누른다.
4. "Do you trust the authors of the files in this folder?" 라는 창이 뜨면 `Yes, I trust the authors` 를 클릭한다.

### 방법 B. 단축키로 폴더 열기

| 운영체제 | 단축키 |
|----------|--------|
| macOS | `Cmd + O` → 폴더 선택 |
| Windows / Linux | `Ctrl + K`, 이어서 `Ctrl + O` |

### 폴더가 제대로 열렸는지 확인하기

Side Bar(Explorer)의 맨 위에 폴더 이름이 대문자로 표시되면 성공이다.

예시:

```text
PYTHON-STUDY
  ▷ (아직 파일 없음)
```

### 새 파일 만들기

폴더를 연 뒤 파일을 만드는 방법은 세 가지이다.

**방법 1 — Explorer에서 아이콘 클릭**

1. Side Bar(Explorer) 안에서 폴더 이름 위에 마우스를 올린다.
2. 오른쪽에 아이콘 네 개가 나타난다. 맨 왼쪽 아이콘(종이에 + 표시)을 클릭한다.
3. 파일 이름을 입력하고 Enter를 누른다.

**방법 2 — 오른쪽 클릭 메뉴**

1. Explorer 빈 공간에서 오른쪽 클릭(마우스 우클릭)을 한다.
2. `New File` 을 선택한다.
3. 파일 이름을 입력하고 Enter를 누른다.

**방법 3 — 단축키**

`Ctrl + N` (macOS: `Cmd + N`) 으로 새 탭을 열고,
`Ctrl + Shift + S` 또는 `Ctrl + S`로 저장할 때 이름을 지정한다.

### Python 파일 이름 규칙

| 규칙 | 이유 |
|------|------|
| 반드시 `.py` 로 끝내기 | VS Code가 Python 파일로 인식하고 문법 색상을 표시해 준다 |
| 공백 대신 `-` 또는 `_` 사용 | `hello world.py` 대신 `hello_world.py` 로 만든다 |
| 소문자만 사용 | `Hello.py` 보다 `hello.py` 가 관행상 안전하다 |
| 숫자로 시작하지 않기 | `1hello.py` 는 Python에서 가져올 때 오류가 난다 |

### 직접 해보기

1. 공부용 폴더를 VS Code에서 연다.
2. Explorer에서 `hello.py` 파일을 만든다.
3. Explorer에 `hello.py` 가 표시되는지 확인한다.

```text
내가 만든 파일 이름:
________________________________

파일이 Explorer에 보이는가 (예 / 아니오):
________________________________
```

완료 체크: [ ] Explorer에 hello.py 파일이 보인다

## 파트 3. Python 파일 작성과 실행

### 코드 입력하기

`hello.py` 를 열고 아래 코드를 입력한다.

```python
print("Hello, VS Code")
```

입력 후 반드시 저장한다.

| 운영체제 | 저장 단축키 |
|----------|-------------|
| macOS | `Cmd + S` |
| Windows / Linux | `Ctrl + S` |

저장하지 않으면 파일 탭에 점(●) 표시가 남아 있다.
저장하면 점이 없어진다.

### 실행 방법 비교

Python 파일을 실행하는 방법은 두 가지가 있다.

#### 방법 A. 터미널에서 직접 명령 입력 (권장)

터미널을 열고 아래 명령을 입력한다.

```bash
python3 hello.py
```

Windows에서 `python3`이 안 되면:

```bash
python hello.py
```

결과:

```text
Hello, VS Code
```

#### 방법 B. ▶ 버튼 클릭 (Run Python File)

1. `hello.py` 파일이 Editor에 열려 있는 상태에서
2. 오른쪽 위 모서리의 ▶ (삼각형) 버튼을 클릭한다.
3. 하단 Terminal Panel이 자동으로 열리며 결과가 표시된다.

### 두 방법의 차이점

| 항목 | 터미널 직접 입력 | ▶ 버튼 클릭 |
|------|-----------------|------------|
| 어느 파일을 실행하는지 | 내가 직접 파일 이름을 입력 | 지금 Editor에 열린 파일 자동 실행 |
| 작업 디렉터리 | 터미널이 현재 있는 폴더 기준 | VS Code가 정한 폴더 기준 |
| 추가 옵션 전달 | 가능 (`python3 hello.py --name=kim`) | 기본적으로 불가 |
| 배우는 이유 | 터미널 사용 습관을 기르기 위해 | 빠르게 확인할 때 편리 |

처음에는 터미널에서 직접 입력하는 방법에 익숙해지는 것이 좋다.

### 코드 추가 연습

```python
print("Hello, VS Code")
print("공부 시작!")
print("오늘 날짜:", "2026-05-22")
```

저장 후 다시 실행하면 세 줄이 나와야 한다.

```text
Hello, VS Code
공부 시작!
오늘 날짜: 2026-05-22
```

### 직접 해보기

1. `hello.py` 에 `print("Hello, VS Code")` 를 입력하고 저장한다.
2. 터미널에서 `python3 hello.py` 로 실행한다.
3. ▶ 버튼으로도 실행해서 결과가 같은지 비교한다.

```text
터미널 실행 결과:
________________________________

▶ 버튼 실행 결과:
________________________________

두 결과가 같은가 (예 / 아니오):
________________________________
```

완료 체크: [ ] 두 가지 방법으로 hello.py를 실행했다

## 파트 4. VS Code 터미널 사용

### 터미널 열기

VS Code 안에 터미널이 내장되어 있다.
별도의 앱을 열지 않아도 코드를 수정하고 바로 실행할 수 있다.

| 방법 | 설명 |
|------|------|
| 단축키 | Ctrl + ` (백틱, 키보드 숫자 1 왼쪽 키) |
| 메뉴 | 상단 메뉴 `Terminal` → `New Terminal` |
| 명령 팔레트 | `Ctrl + Shift + P` → `Terminal: Create New Terminal` |

### 터미널이 열리는 위치 확인

터미널이 처음 열리면 현재 폴더 위치를 확인한다.

```bash
pwd
```

출력 예시 (macOS):

```text
/Users/username/python-study
```

출력 예시 (Windows):

```text
C:\Users\username\python-study
```

폴더 위치가 맞지 않으면 `cd` 명령으로 이동한다.

```bash
cd /Users/username/python-study
```

### 터미널 기본 명령

| 명령 | 설명 | 예시 |
|------|------|------|
| `pwd` | 현재 위치(폴더) 확인 | `pwd` |
| `ls` | 현재 폴더 안의 파일 목록 보기 (macOS/Linux) | `ls` |
| `dir` | 현재 폴더 안의 파일 목록 보기 (Windows) | `dir` |
| `cd 폴더이름` | 폴더 이동 | `cd python-study` |
| `cd ..` | 상위 폴더로 이동 | `cd ..` |
| `python3 파일.py` | Python 파일 실행 | `python3 hello.py` |

### 터미널 여러 개 열기

터미널은 동시에 여러 개를 열 수 있다.
`+` 아이콘을 클릭하거나 단축키를 다시 누르면 새 터미널이 생긴다.

터미널이 여러 개 있을 때는 하단의 탭 목록에서 이름을 클릭해 전환한다.

### 터미널 이름 바꾸기

터미널이 여러 개일 때 이름을 구분해 두면 편하다.

1. 하단 터미널 탭에서 이름 부분에 오른쪽 클릭을 한다.
2. `Rename` 을 선택한다.
3. 새 이름을 입력하고 Enter를 누른다.

예시: `python 실행용`, `git 명령용` 처럼 용도별로 이름을 붙일 수 있다.

### 터미널 닫기

| 방법 | 설명 |
|------|------|
| 터미널 탭의 X 클릭 | 해당 터미널만 닫기 |
| `exit` 입력 후 Enter | 터미널 세션 종료 |
| 단축키 `Ctrl + ` 다시 누르기 | 터미널 패널 보이기/숨기기 토글 |

### 직접 해보기

1. `Ctrl + `` 로 터미널을 연다.
2. `pwd` 를 입력해 현재 위치를 확인한다.
3. `ls` (또는 `dir`) 를 입력해 `hello.py` 가 보이는지 확인한다.
4. 터미널을 하나 더 열고 이름을 `연습용` 으로 바꾼다.

```text
pwd 결과:
________________________________

ls/dir 결과에 hello.py가 있는가 (예 / 아니오):
________________________________

새로 만든 터미널 이름:
________________________________
```

완료 체크: [ ] 터미널을 열고 pwd, ls 명령을 사용했다

## 파트 5. 자주 쓰는 단축키 실습

### 반드시 외워야 할 단축키 5개

처음부터 모두 외우려 하지 않아도 된다.
아래 다섯 개만 손에 익히면 작업 속도가 눈에 띄게 빨라진다.

| 단축키 (macOS / Windows) | 이름 | 언제 쓰는가 |
|--------------------------|------|-------------|
| `Cmd+S` / `Ctrl+S` | 저장 | 코드를 수정할 때마다 |
| `Cmd+Z` / `Ctrl+Z` | 실행 취소 | 방금 한 작업을 되돌릴 때 |
| `Cmd+Shift+P` / `Ctrl+Shift+P` | 명령 팔레트 열기 | 기능을 이름으로 검색할 때 |
| `F5` | 디버그 모드 실행 | 중단점을 걸고 단계별로 실행할 때 |
| `Ctrl+`` | 터미널 열기/닫기 | 코드 실행하러 터미널 갈 때 |

### Ctrl+S — 저장

코드를 입력하고 저장하지 않으면 실행해도 변경 내용이 반영되지 않는다.
저장 여부는 탭 이름 옆의 점(●)으로 확인한다.

```text
저장 전: hello.py ●
저장 후: hello.py
```

실습: `hello.py` 에 새 줄을 추가하고 탭에 점이 생기는지 확인한다.
그 다음 `Ctrl+S` 를 눌러 점이 없어지는지 확인한다.

### Ctrl+Z — 실행 취소

코드를 잘못 삭제하거나 실수로 덮어썼을 때 되돌린다.
여러 번 연속으로 누르면 더 이전 상태로 돌아간다.

반대로 `Ctrl+Shift+Z` (macOS: `Cmd+Shift+Z`) 를 누르면 앞으로 다시 실행(Redo) 이다.

실습: `hello.py` 에서 한 줄을 삭제한 뒤 `Ctrl+Z` 를 눌러 복구한다.

### Ctrl+Shift+P — 명령 팔레트

VS Code의 모든 기능을 이름으로 검색할 수 있는 입력창이다.
메뉴를 일일이 찾아다닐 필요 없이 원하는 기능의 이름을 입력하면 바로 실행된다.

자주 쓰는 명령 팔레트 검색어:

| 입력어 | 기능 |
|--------|------|
| `Python: Select Interpreter` | Python 버전 선택 |
| `Terminal: Create New Terminal` | 새 터미널 열기 |
| `Format Document` | 코드 자동 정렬 |
| `Reload Window` | VS Code 창 새로 고침 |
| `Open Settings` | 설정 파일 열기 |

실습:
1. `Ctrl+Shift+P` 를 누른다.
2. `Python: Select` 를 입력한다.
3. `Python: Select Interpreter` 가 목록에 나타나는지 확인한다.
4. Enter를 눌러 인터프리터 목록을 확인한다.

### F5 — 디버그 실행

F5를 누르면 디버그 모드로 파일을 실행한다.
중단점(Breakpoint) 없이 실행하면 일반 실행과 동일하게 동작한다.
나중에 버그를 찾을 때 중단점과 함께 쓴다.

실습:
1. `hello.py` 가 Editor에 열려 있는 상태에서 `F5` 를 누른다.
2. 실행 환경을 물어보면 `Python File` 을 선택한다.
3. 결과가 터미널에 출력되는지 확인한다.

### 직접 해보기

아래 단축키를 순서대로 한 번씩 눌러 본다.

```text
1. hello.py에 print("단축키 연습") 을 추가한다.
2. Ctrl+S 로 저장한다.  탭의 점(●)이 사라졌는가: ________

   Format Document 가 보이는가: ________

   결과가 나왔는가: ________
```

## 파트 6. Python 확장 설치 확인

### Python 확장이 필요한 이유

VS Code 자체는 텍스트 편집기이다.
Python 코드를 이해하고, 문법 오류를 표시하고, 인터프리터를 연결하려면
**Python 확장(Extension)** 이 설치되어 있어야 한다.

Python 확장이 하는 일:

- 코드에 색상 입히기 (Syntax Highlighting)
- 오타나 문법 오류에 빨간 밑줄 표시
- 자동 완성 (변수 이름, 함수 이름 제안)
- ▶ 버튼으로 파일 실행 지원
- Status Bar에 Python 버전 표시

### Extensions 탭 열기

Activity Bar에서 퍼즐 조각 아이콘을 클릭하거나
단축키 `Ctrl+Shift+X` (macOS: `Cmd+Shift+X`) 를 누른다.

### Python 확장 설치 여부 확인하기

1. Extensions 탭 검색창에 `Python` 을 입력한다.
2. 목록에서 `Python` (발행처: Microsoft) 을 찾는다.
3. 버튼 상태를 확인한다.

| 버튼 표시 | 의미 |
|-----------|------|
| `Install` | 아직 설치되지 않았다 → 클릭해서 설치 |
| `Disable` 또는 `Uninstall` | 이미 설치된 상태이다 → 그대로 두면 된다 |

### Python 확장 설치하기 (아직 없는 경우)

1. `Python` (Microsoft) 항목을 클릭한다.
2. `Install` 버튼을 클릭한다.
3. 설치가 완료되면 `Reload Required` 버튼이 나타날 수 있다. 클릭해서 VS Code를 재시작한다.

### 추가로 유용한 확장

| 확장 이름 | 발행처 | 역할 |
|-----------|--------|------|
| Pylance | Microsoft | Python 자동 완성 및 타입 검사 강화 |
| Python Indent | Kevin Rose | 들여쓰기 자동 처리 |
| indent-rainbow | oderwat | 들여쓰기 깊이를 색상으로 표시 |

처음에는 `Python` (Microsoft) 하나만 있어도 충분하다.

### Python 인터프리터 연결 확인

확장이 설치되어 있더라도 인터프리터가 연결되지 않으면 제대로 동작하지 않는다.

1. `Ctrl+Shift+P` → `Python: Select Interpreter` 를 실행한다.
2. 목록에서 `python3.x` 형태의 항목을 선택한다.
3. Status Bar 아래쪽에 선택한 Python 버전이 표시되는지 확인한다.

```text
내가 선택한 Python 인터프리터:
________________________________

Status Bar에서 버전이 표시되는가 (예 / 아니오):
________________________________
```

### 직접 해보기

1. `Ctrl+Shift+X` 로 Extensions 탭을 연다.
2. `Python` 을 검색해 Microsoft 확장이 설치되어 있는지 확인한다.
3. `Ctrl+Shift+P` → `Python: Select Interpreter` 로 인터프리터를 선택한다.
4. `hello.py` 에서 `print(` 까지만 입력하고 자동 완성이 나오는지 확인한다.

```text
Python 확장 설치 상태:
________________________________

자동 완성이 나타났는가 (예 / 아니오):
________________________________
```

완료 체크: [ ] Python 확장이 설치되어 있고 인터프리터가 연결되어 있다

## 막혔을 때 — 자주 겪는 5가지 상황

### 상황 1. "python3: command not found" 또는 "'python3' is not recognized"

**원인**: Python이 설치되지 않았거나, 시스템 PATH에 등록되지 않았다.

**해결 방법**:

1. 터미널에서 `python --version` 을 먼저 시도한다. (Windows는 `python3` 대신 `python` 이 맞을 수 있다)
2. 아무것도 안 된다면 Python 공식 사이트(python.org)에서 다시 설치한다.
3. Windows 설치 시 "Add Python to PATH" 체크박스를 반드시 선택해야 한다.
4. 설치 후 VS Code와 터미널을 완전히 닫았다가 다시 연다.

### 상황 2. 파일을 실행했는데 이전 결과가 그대로 나온다

**원인**: 코드를 수정한 뒤 저장하지 않았다.

**해결 방법**:

1. Editor 탭에 점(●) 표시가 있는지 확인한다.
2. 점이 있으면 `Ctrl+S` 로 저장한다.
3. 저장 후 다시 실행한다.

자동 저장을 켜려면: `File` → `Auto Save` 를 체크한다.

### 상황 3. "No such file or directory: 'hello.py'"

**원인**: 터미널의 현재 위치가 `hello.py` 가 있는 폴더가 아니다.

**해결 방법**:

1. `pwd` 로 현재 위치를 확인한다.
2. `ls` (또는 `dir`) 로 파일 목록을 확인한다. `hello.py` 가 보이는가?
3. 없다면 `cd` 로 올바른 폴더로 이동한다.

예시:

```bash
cd /Users/username/python-study
ls
python3 hello.py
```

### 상황 4. ▶ 버튼이 보이지 않는다

**원인**: Python 확장이 설치되지 않았거나, 파일이 `.py` 형식이 아니다.

**해결 방법**:

1. 파일 이름이 `.py` 로 끝나는지 확인한다.
2. Extensions 탭에서 Python(Microsoft) 확장이 설치되어 있는지 확인한다.
3. `Ctrl+Shift+P` → `Python: Select Interpreter` 로 인터프리터를 선택한다.
4. 그래도 안 되면 VS Code를 닫았다가 다시 연다.

### 상황 5. 한글이 깨져서 출력된다

**원인**: 파일 인코딩이 UTF-8이 아니거나, Windows에서 터미널 코드 페이지가 다르다.

**해결 방법**:

- **파일 인코딩 확인**: Status Bar 오른쪽에 `UTF-8` 이라고 표시되는지 확인한다. 다른 값이면 클릭해서 `UTF-8` 로 바꾸고 저장한다.
- **Windows 터미널**: 터미널에서 `chcp 65001` 을 입력한 뒤 다시 실행한다.
- **Python 코드 첫 줄에 추가** (구버전 Python):

```python
# -*- coding: utf-8 -*-
print("안녕하세요")
```

## 에러 메시지 빠른 참조표

| 보이는 메시지 | 원인 | 먼저 할 일 |
|---------------|------|------------|
