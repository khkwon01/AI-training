# VS Code Workbook Page 01

## 목표

VS Code를 열고, 공부용 폴더를 열고, Python 파일을 만들고, 터미널에서 직접 실행해 본다.

## 따라 하기 순서

### 0단계. 준비 확인

터미널 또는 시스템 명령창에서 아래를 확인한다.

```bash
python3 --version
```

Windows에서 `python3`이 안 되면:

```bash
python --version
```

직접 적어 보기:

```text
내 Python 버전:
________________________________
```

### 1단계. 공부용 폴더 정하기

예:

```text
python-study/
```

직접 적어 보기:

```text
내가 사용할 폴더 이름:
________________________________
```

### 2단계. VS Code에서 폴더 열기

할 일:

- VS Code 실행
- `Open Folder` 선택
- 방금 정한 폴더 열기

확인:

- 왼쪽 Explorer에 폴더 이름이 보이는가
- 빈 화면이 아니라 폴더 기준 화면으로 바뀌었는가

### 3단계. 새 파일 만들기

파일 이름:

```text
hello.py
```

코드:

```python
print("Hello, VS Code")
```

추가 연습:

```python
print("공부 시작!")
```

### 4단계. 터미널 열기

VS Code 안에서 터미널을 열고 아래 명령을 적는다.

```bash
pwd
ls
python3 hello.py
```

Windows에서는 `python hello.py`도 가능하다.

### 5단계. 결과 확인하기

아래가 보이면 성공이다.

```text
Hello, VS Code
```

두 줄을 적었다면 아래처럼 보여야 한다.

```text
Hello, VS Code
공부 시작!
```

### 6단계. Python 인터프리터 확인하기

아래 둘 중 하나를 해 본다.

- 상태 표시줄의 Python 버전 클릭
- `Cmd/Ctrl + Shift + P` → `Python: Select Interpreter`

직접 적어 보기:

```text
내가 선택한 Python:
________________________________
```

## 자주 하는 실수

- `.py` 없이 저장하기
- 다른 폴더를 열어 놓고 파일 위치를 헷갈리기
- 터미널을 열지 않고 실행 방법을 찾다가 멈추기
- Python 확장은 설치했지만 인터프리터를 고르지 않기
- 저장하지 않고 실행하기

## 확인 체크리스트

- VS Code에서 폴더를 열 수 있는가
- `.py` 파일을 만들 수 있는가
- 터미널을 열 수 있는가
- `python3 파일이름.py`로 실행할 수 있는가
- `Python: Select Interpreter`를 찾을 수 있는가

## 막혔을 때 바로 확인할 것

```text
1. 폴더를 열었는가
2. 파일 이름이 hello.py 인가
3. 터미널 위치가 그 폴더 안인가
4. Python 인터프리터가 선택되어 있는가
```

## 에러가 보이면 이렇게 보기

| 보이는 메시지 | 먼저 할 일 |
|---------------|------------|
| `python3: command not found` | Python 설치 확인, Windows면 `python`으로 다시 시도 |
| `No such file or directory` | `pwd`, `ls`로 현재 폴더와 파일 이름 확인 |
| 실행 결과가 안 바뀜 | 저장했는지 확인 후 다시 실행 |
