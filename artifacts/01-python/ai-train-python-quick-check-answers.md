## 1. Quick Check Set 01 — 핵심 답 정리

### 1-1. 변수와 자료형

```python
# Q: 아래 코드의 출력 결과는?
이름 = "김민준"
나이 = 17
print(type(이름))   # <class 'str'>
print(type(나이))   # <class 'int'>
```

**채점 포인트**
| 항목 | 배점 | 핵심 키워드 |
|------|------|------------|
| `str` 정확히 출력 | 1점 | `<class 'str'>` |
| `int` 정확히 출력 | 1점 | `<class 'int'>` |
| `type()` 함수 사용 이유 설명 | 1점 | "자료형 확인 함수" |

---

### 1-2. 조건문 (if / elif / else)

```python
# Q: 점수에 따라 등급을 출력하는 코드를 완성하시오
점수 = int(input("점수를 입력하세요: "))

if 점수 >= 90:
    print("A")
elif 점수 >= 80:
    print("B")
elif 점수 >= 70:
    print("C")
else:
    print("F")
```

**채점 포인트**
| 항목 | 배점 | 핵심 키워드 |
|------|------|------------|
| `>=` 비교 연산자 올바른 사용 | 1점 | `>=` (크거나 같다) |
| `elif` 체인 순서 올바름 | 1점 | 90 → 80 → 70 순서 |
| `else` 마지막에 위치 | 1점 | 나머지 모든 경우 |

> ⚠️ 자주 틀리는 포인트: `90 >= 점수` 처럼 순서를 반대로 쓰면 **논리적으로 틀릴 수 있음**

---

### 1-3. 반복문 (for / while)

```python
# Q: 1부터 5까지 합계를 구하는 두 가지 방법

# 방법 1 — for 문
합계 = 0
for i in range(1, 6):
    합계 += i
print(합계)  # 15

# 방법 2 — while 문
합계 = 0
i = 1
while i <= 5:
    합계 += i
    i += 1
print(합계)  # 15
```

**채점 포인트**
| 항목 | 배점 | 핵심 키워드 |
|------|------|------------|
| `range(1, 6)` 범위 정확 | 1점 | 끝값 포함 안 됨 주의 |
| `합계 += i` 누적 방식 | 1점 | `+=` 연산자 |
| while 탈출 조건 존재 | 1점 | `i += 1` 없으면 무한루프 |

## 2. Quick Check Set 02 — 핵심 답 정리

### 2-1. 리스트와 인덱싱

```python
# Q: 아래 리스트에서 "바나나"를 출력하고, 마지막 요소를 삭제하시오
과일 = ["사과", "바나나", "포도", "딸기"]

print(과일[1])      # 바나나
과일.pop()          # "딸기" 삭제
print(과일)         # ['사과', '바나나', '포도']
```

**채점 포인트**
| 항목 | 배점 | 핵심 키워드 |
|------|------|------------|
| 인덱스 `[1]` 정확 | 1점 | 인덱스는 0부터 시작 |
| `.pop()` 사용 | 1점 | 마지막 요소 제거 |
| 결과 리스트 출력 정확 | 1점 | 딸기가 사라진 상태 |

---

### 2-2. 함수 정의와 호출

```python
# Q: 두 수를 받아서 곱을 반환하는 함수를 작성하시오
def 곱하기(a, b):
    결과 = a * b
    return 결과

print(곱하기(3, 4))   # 12
print(곱하기(7, 5))   # 35
```

**채점 포인트**
| 항목 | 배점 | 핵심 키워드 |
|------|------|------------|
| `def` 키워드 사용 | 1점 | 함수 선언 |
| 매개변수 2개 정의 | 1점 | `(a, b)` |
| `return` 으로 값 반환 | 1점 | print가 아닌 return |

> ⚠️ `print(결과)` 와 `return 결과` 의 차이를 모르면 -1점

---

### 2-3. 딕셔너리 활용

```python
# Q: 학생 정보를 딕셔너리로 만들고, 이름과 성적을 출력하시오
학생 = {
    "이름": "이지은",
    "학년": 2,
    "성적": 95
}

print(학생["이름"])   # 이지은
print(학생["성적"])   # 95

# 새 키 추가
학생["반"] = "3반"
print(학생)
```

**채점 포인트**
| 항목 | 배점 | 핵심 키워드 |
|------|------|------------|
| `{}` 중괄호로 딕셔너리 생성 | 1점 | 리스트 `[]` 와 혼동 금지 |
| `["키이름"]` 으로 값 접근 | 1점 | 인덱스 번호 아님 |
| 새 키 추가 문법 정확 | 1점 | `딕셔너리["새키"] = 값` |

## 자주 하는 실수

| 실수 유형 | 실제 에러 메시지 | 올바른 코드 |
|-----------|----------------|------------|
| 인덱스 범위 초과 | `IndexError: list index out of range` | `과일[3]` → 길이 확인 후 접근 |
| 들여쓰기 빠짐 | `IndentationError: expected an indented block` | `if` 블록 안에 반드시 들여쓰기 |
| `return` 대신 `print` | 함수가 `None` 반환 | `print(결과)` → `return 결과` |
| `range(1, 5)` 로 5 포함 시도 | 출력에 5가 없음 (에러는 안 남) | `range(1, 6)` 으로 수정 |
| 딕셔너리를 리스트처럼 접근 | `TypeError: list indices must be integers` | `학생[0]` → `학생["이름"]` |
| `elif` 순서 역전 | 논리 오류 (에러 없이 틀린 답 출력) | 큰 조건을 항상 먼저 작성 |
