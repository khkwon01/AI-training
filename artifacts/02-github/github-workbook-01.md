# Workbook Page 01

## 목표

아주 작은 변경 하나를 `issue -> branch -> PR -> AI review -> human review` 흐름으로 직접 따라 해 본다.

## 준비

이번 페이지에서는 아래처럼 아주 작은 작업을 기준으로 연습한다.

- 안내 문장 1개를 더 쉬운 말로 바꾸기
- 체크리스트 항목 1개 추가하기
- 예시 설명 1개 보완하기

처음에는 "지금 바로 말로 설명할 수 있는 작은 수정"이면 충분하다.

## 흐름 요약

1. 할 일을 `issue`로 적는다
2. 그 일만 처리할 `branch`를 만든다
3. 작은 변경을 한다
4. `PR`에 목표, 이유, 리뷰 요청을 적는다
5. AI review로 빠진 점을 먼저 확인한다
6. human review로 초보자 관점까지 확인한다

## 따라 하기 순서

### 1단계. issue 만들기

작업 예시:

`lesson checklist에 review 항목 1개 추가하기`

직접 써 보기:

```text
제목:
설명:
```

### 2단계. branch 이름 정하기

예:

`ai-train-github-checklist-update`

직접 써 보기:

```text
branch 이름:
```

### 3단계. 작은 변경 적기

예:

- checklist 문장을 더 쉽게 바꾸기
- references 확인 항목 추가하기

직접 고를 수 있는 초보자용 변경 예시:

- 문장 1개를 짧게 바꾸기
- 예시 1개를 더 구체적으로 바꾸기
- 체크리스트 항목 1개 추가하기

### 4단계. PR 설명 쓰기

```text
목표: 초보자용 checklist를 더 쉽게 이해되게 수정
이유: 현재 문장이 조금 추상적임
리뷰 요청: 문장이 쉬운지 확인해 주세요
```

직접 써 보기:

```text
목표:
이유:
리뷰 요청:
```

### 5단계. AI review 요청하기

확인할 것:

- 범위를 벗어나지 않았는가
- 문장이 너무 어려운가
- 빠진 항목은 없는가

짧게 적어 보기:

```text
AI에게 먼저 확인받고 싶은 점:
```

### 6단계. human review 보기

확인할 것:

- 초보자 입장에서 실제로 이해되는가
- AI review가 못 본 부분은 없는가

짧게 적어 보기:

```text
사람에게 특히 봐 달라고 할 점:
```

## 연습 1. 쉬운 말로 바꾸기

아래 문장을 더 쉬운 말로 바꿔 보자.

```text
다음 사람이 이어서 보기 위한 메모가 있는가
```

예:

```text
다음 사람이 바로 이해할 수 있게 설명이 적혀 있는가
```

## 연습 2. 작은 작업 고르기

아래 중 초보자 첫 PR 연습으로 가장 좋은 것을 골라 보자.

- 문서 전체 제목 형식을 모두 바꾸기
- 체크리스트 항목 1개 추가하기
- 여러 파일 구조를 한 번에 다시 정리하기

정답에 가까운 선택:

```text
체크리스트 항목 1개 추가하기
```

이유를 한 줄로 적어 보자.

```text
이유:
```

## 연습 3. 리뷰 요청 문장 완성하기

상황:

- 변경 내용: 설치 설명 아래에 "예시 명령어를 한 줄씩 실행하세요" 문장을 추가했다
- 목적: 초보자가 순서를 놓치지 않게 하려는 것이다

아래 빈칸을 채워 보자.

```text
리뷰 요청: ________________________________________________
```

예시 답:

```text
리뷰 요청: 초보자가 순서대로 따라 읽기 쉬운지 확인해 주세요
```

## 교사용 빠른 확인

학습자가 아래 두 가지를 말할 수 있는지 확인하면 좋다.

- 왜 첫 PR은 작아야 하는가
- 왜 AI review 뒤에도 사람 review가 필요한가

## 확인 체크리스트

- issue가 한 줄로 설명되는가
- issue가 너무 크지 않은가
- branch 이름이 작업과 연결되는가
- PR 설명에 목표와 이유가 있는가
- AI review와 사람 review를 모두 생각했는가
