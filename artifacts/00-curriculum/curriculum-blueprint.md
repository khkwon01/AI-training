# Blueprint

## 한 줄 목표

초보자가 AI를 활용해 쉽고 실용적으로 코딩을 배우고, 작은 프로그램을 만들고, GitHub로 관리하고, AWS에 배포해보는 전체 교육 과정을 만든다.

## 중요한 전제

- 이 프로젝트의 목표는 `harness`를 가르치는 것이 아니다.
- `harness`는 내부적으로 교육 자료를 만들고 개선하기 위한 작업 방식이다.
- 학습자가 실제로 보게 될 결과물은 모두 `초보자를 위한 쉬운 교육 자료`여야 한다.

## 교육 자료가 가져야 할 성격

모든 결과물은 아래 기준을 만족해야 한다.

1. 쉬운 개념 설명이 먼저 나온다.
2. 왜 배우는지 이유가 분명해야 한다.
3. 주요 목차가 명확해야 한다.
4. 따라 하기 순서가 단계별로 있어야 한다.
5. 예제와 실습이 포함되어야 한다.
6. 혼자서도 복습할 수 있게 체크리스트가 있어야 한다.
7. 책 교재처럼 읽히도록 문장 흐름이 자연스러워야 한다.

## 대상 학습자

- 코딩이 익숙하지 않은 초보자
- Python, GitHub, AI 도구를 처음 접하는 학습자
- "AI를 어떻게 써야 하는지"부터 배우고 싶은 학습자
- 단순 설명보다 직접 따라 하면서 배우는 편이 쉬운 학습자

## 전체 과정의 큰 흐름

### 1. AI와 함께 배우는 코딩의 기본 이해

- AI는 무엇을 잘하고 무엇을 못하는가
- AI에게 어떻게 질문해야 하는가
- AI가 준 답을 왜 검토해야 하는가

### 2. Python 기초

- Python 실행하기
- 변수와 자료형
- 조건문과 반복문
- 함수
- class와 object
- module과 import
- 파일과 JSON 다루기
- 간단한 테스트와 디버깅

### 3. GitHub 기초

- 저장소란 무엇인가
- clone, add, commit, push
- branch와 pull request
- AI review와 사람 review의 차이

### 4. AI를 활용한 실습 코딩

- AI로 초안 만들기
- 사람이 읽고 수정하기
- 테스트로 확인하기
- 결과를 문서로 남기기

### 5. 작은 예제 프로그램 만들기

- 요구사항 정리
- 작은 기능부터 구현
- 수정과 개선 반복

### 6. AWS 배포 기초

- 배포란 무엇인가
- 작은 Python 프로그램을 어떻게 올리는가
- 배포 후 무엇을 확인해야 하는가

- research는 외부 자료를 읽고 교육 내용을 개선하기 위해 사용한다

- 학습자용 결과물에는 이 내부 구조를 전면에 내세우지 않는다
- 학습자에게는 "쉽게 이해되는 설명"과 "직접 따라 하는 흐름"이 더 중요하다
