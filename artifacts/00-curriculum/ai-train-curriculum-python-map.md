# ai-train Python Curriculum Map

## 목표

지금까지 만들어진 Python beginner 자료를 한눈에 보고, 어떤 순서로 공부하면 좋은지 알 수 있게 정리한다.

## 권장 학습 순서

### 1단계. 기초 문법 익히기

1. [Python Basics Chapter 01](../01-python/ai-train-python-chapter-01-print-and-run.md)
   - 실행, 자료형, 조건문, 반복문, 함수, class, module

### 2단계. 파일과 데이터 다루기

2. [Python Basics Chapter 04: 파일과 JSON](../01-python/ai-train-python-chapter-04-files-and-json.md)
   - 파일 읽기/쓰기, JSON, 기본 assert

### 3단계. 오류와 디버깅 익히기

3. [Python Basics Chapter 05: 디버깅](../01-python/ai-train-python-chapter-05-debugging.md)
   - 오류 메시지, NameError, TypeError, IndexError, print 디버깅

### 4단계. 프로젝트 구조 이해하기

4. [Python Basics Chapter 06: 프로젝트 구조](../01-python/ai-train-python-chapter-06-project-structure.md)
   - `main.py`, `utils.py`, `data/`, `tests/`, `snake_case`, import

### 5단계. 실행 환경 이해하기

5. [Python Basics Chapter 07: 환경](../01-python/ai-train-python-chapter-07-environment.md)
   - 환경변수, dependency, path

6. [Python Basics Chapter 09: venv와 pip](../01-python/ai-train-python-chapter-09-venv-and-pip.md)
   - `venv`, `pip`, `requirements.txt`

### 6단계. 예외와 후속 문법

7. [Python Basics Chapter 08: 예외 처리](../01-python/ai-train-python-chapter-08-exceptions.md)
   - `try/except`

8. [Python Basics Chapter 10: comprehension과 datetime](../01-python/ai-train-python-chapter-10-comprehension-datetime.md)
   - comprehension, datetime

### 7단계. 종합 연습

9. [Python Cumulative Practice 01](../01-python/ai-train-python-practice-cumulative-01.md)
10. [Answer Guide](../01-python/ai-train-python-practice-cumulative-01-answers.md)

## 학습 팁

- Chapter 01-03은 반드시 순서대로 보는 편이 좋다.
- Chapter 04-07은 "실제 프로젝트 감각"을 키우는 구간이다.
- Chapter 08은 후속 확장 장이므로 너무 급하게 들어가지 않아도 된다.
- 종합 연습은 Chapter 01-07을 어느 정도 본 뒤에 푸는 편이 좋다.

## 교사용 메모

- 초보자는 `class`, `exception`, `venv`에서 가장 자주 멈춘다.
- 따라서 Chapter 01, 06, 07은 추가 예시와 쉬운 설명을 더 붙일 여지가 크다.
- 필요한 경우 [Teacher Note Template](../01-python/ai-train-python-teacher-note-template.md)를 함께 사용한다.
