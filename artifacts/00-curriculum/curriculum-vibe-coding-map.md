# Coding 학습 지도

## 목표

AI를 활용해 아이디어를 빠르게 코드로 만들고, 검증하고, GitHub과 AWS와 연결하는 실전 개발 방식을 익힌다.

---

## Vibe Coding이란

AI에게 원하는 기능을 설명하고, AI가 만든 초안을 읽고 수정하고, 검증하는 방식의 코딩이다.

```
내가 원하는 것 설명
      ↓
AI가 초안 생성
      ↓
내가 읽고 이해
      ↓
직접 실행해서 확인
      ↓
필요하면 수정 요청
      ↓
다음 기능으로
```

"AI가 다 짜주니까 나는 아무것도 안 해도 된다"는 오해가 있다. 실제로는 **내가 방향을 정하고, AI가 초안을 만들고, 내가 검증한다**.

## 학습 팁

- **작게 쪼개기가 핵심**: "메모 앱 만들어줘"보다 "메모 추가 함수 만들어줘"처럼 작은 단위로 요청한다
- **모든 코드를 직접 실행해서 확인**: 실행이 된다고 맞는 게 아니다. 다양한 입력으로 테스트하자
- **루프를 두려워하지 말자**: AI가 처음에 완벽한 코드를 주는 경우는 드물다. 수정→재요청→확인이 정상이다
- **commit을 자주 하자**: AI가 파일을 잘못 수정해도 `git restore`로 되돌릴 수 있다

## Vibe Coding에서 흔한 실수

| 실수 | 문제 | 해결 |
|------|------|------|
| 큰 기능을 한꺼번에 요청 | 이해 못 하는 긴 코드가 나옴 | 기능을 3~5단계로 쪼개서 요청 |
| 코드 읽지 않고 실행 | 오류 원인을 모름 | 항상 한 줄씩 읽고 이해 후 실행 |
| 오류 나면 바로 AI에 재요청 | 같은 오류 반복 | 오류 메시지를 30초 이상 직접 읽은 후 요청 |
| 검증 없이 PR 생성 | 잘못된 코드가 main에 합쳐짐 | 로컬 테스트 통과 후 PR 생성 |
