- AI 페어 프로그래밍이 무엇인지, 왜 쓰는지 이해한다

- 실수했을 때 AI와 함께 디버깅하는 흐름을 경험한다
- 반복되는 작업을 AI에게 맡기고 나는 더 중요한 설계에 집중하는 방법을 안다

## 먼저 쉬운 설명

혼자 코딩하다 막히면 어떻게 하나요? 구글 검색, Stack Overflow, 유튜브 강의… 시간이 엄청 걸리죠.

AI 페어 프로그래밍은 **옆자리에 항상 시니어 개발자가 앉아 있는 것**과 같습니다. 언제든 물어볼 수 있고, 즉시 코드 예시를 보여주고, 내 코드의 문제점도 찾아줍니다.

하지만 주의할 점이 있어요. AI는 **틀린 코드도 자신 있게** 작성합니다. 그래서 AI가 쓴 코드를 **이해하지 않고 그냥 쓰면** 나중에 더 큰 문제가 생깁니다.

이 장의 핵심은 딱 하나입니다.

> **AI를 도구로 쓰되, 판단은 내가 한다.**

## 1. AI 페어 프로그래밍 기본 흐름

AI와 함께 코딩할 때는 다음 4단계 흐름을 반복합니다.

```
내가 목표를 말한다
    ↓
AI가 코드를 제안한다
    ↓
내가 코드를 읽고 이해한다
    ↓
직접 실행해서 확인한다
```

### 나쁜 예시 (이렇게 하면 안 됩니다)

```python
# AI한테 "파이썬으로 계산기 만들어줘" 라고만 했을 때
# → AI가 200줄짜리 GUI 계산기를 만들어줌
# → 나는 이해 못 하지만 일단 제출함
# → 나중에 버그 발생 → 고칠 수 없음
```

### 좋은 예시 (이렇게 해보세요)

```python
# AI에게 이렇게 요청했을 때:
# "두 숫자를 입력받아서 더하는 함수만 만들어줘.
#  초보자용으로 간단하게, 주석도 달아줘."

def 두수_더하기(첫번째_숫자, 두번째_숫자):
    # 두 숫자를 받아서 합계를 반환하는 함수
    합계 = 첫번째_숫자 + 두번째_숫자
    return 합계

# 직접 실행해서 확인
결과 = 두수_더하기(3, 5)
print(결과)  # 8
```

**핵심**: 요청을 작고 구체적으로 쪼갤수록 AI의 답변이 더 정확해집니다.

## 2. 좋은 프롬프트 작성법

AI에게 코드를 요청할 때 **맥락, 조건, 예시**를 함께 주면 훨씬 좋은 결과가 나옵니다.

### 프롬프트 기본 구조

```
[배경] 나는 지금 ___를 만들고 있어.
[요청] ___ 기능을 구현하고 싶어.
[조건] ___ 라이브러리만 써줘 / 초보자용으로 / 주석 포함해서
[예시] 입력이 ___ 이면 출력이 ___ 이어야 해.
```

### 실제 예시: 학생 점수 관리 프로그램

```python
# 프롬프트:
# "학생 이름과 점수를 딕셔너리에 저장하고,
#  평균 점수를 계산하는 함수를 만들어줘.
#  예: {'김철수': 85, '이영희': 92} 가 입력되면
#  평균 88.5를 반환해야 해."

def 평균_점수_계산(학생_점수_딕셔너리):
    """
    학생들의 점수 딕셔너리를 받아 평균을 반환합니다.
    """
    if not 학생_점수_딕셔너리:
        return 0  # 비어있으면 0 반환

    총점 = sum(학생_점수_딕셔너리.values())
    학생수 = len(학생_점수_딕셔너리)
    평균 = 총점 / 학생수
    return 평균

# 테스트
학생들 = {'김철수': 85, '이영희': 92, '박민준': 78}
print(평균_점수_계산(학생들))  # 85.0
```

## 3. AI와 함께 디버깅하기

에러가 났을 때 AI에게 에러 메시지를 **그대로 복사**해서 물어보면 됩니다.

### 디버깅 요청 방법

```
에러 메시지:
TypeError: unsupported operand type(s) for +: 'int' and 'str'

내 코드:
나이 = input("나이를 입력하세요: ")
다음해_나이 = 나이 + 1
print(다음해_나이)

"왜 이런 에러가 나고 어떻게 고치면 돼?"
```

### AI가 설명해줄 내용을 미리 이해하기

```python
# 문제가 있는 코드
나이 = input("나이를 입력하세요: ")  # input()은 항상 문자열을 반환!
다음해_나이 = 나이 + 1               # 문자열 + 숫자 → 에러 발생
print(다음해_나이)

# 수정된 코드
나이 = int(input("나이를 입력하세요: "))  # int()로 숫자로 변환
다음해_나이 = 나이 + 1
print(다음해_나이)  # 정상 작동
```

**팁**: AI의 설명을 받은 뒤에는 **왜 고쳐야 하는지** 스스로 한 번 설명해보세요. 설명할 수 없다면 아직 이해가 덜 된 것입니다.

## 4. AI가 쓴 코드 검토하는 방법

AI 코드를 검토할 때 이 세 가지를 확인하세요.

```python
# AI가 생성한 코드 예시
import os

def 파일_읽기(파일경로):
    with open(파일경로, 'r', encoding='utf-8') as f:
        내용 = f.read()
    return 내용

결과 = 파일_읽기(input("파일 경로: "))
print(결과)
```

**검토 체크포인트**

```python
# ✅ 체크 1: 이 코드가 하는 일을 줄별로 설명할 수 있나?
# - import os  → os 모듈을 불러온다 (근데 여기서 쓰이지 않음 → AI 실수!)
# - with open(...) → 파일을 열고 자동으로 닫는다
# - f.read() → 파일 전체 내용을 읽는다

# ✅ 체크 2: 없는 파일을 입력하면 어떻게 되나?
# FileNotFoundError: [Errno 2] No such file or directory: '없는파일.txt'
# → 에러 처리가 없다! AI가 빠뜨렸음

# ✅ 체크 3: 직접 실행해서 확인했나?
# → 반드시 실행해봐야 함

# 개선된 버전 (AI에게 "에러 처리도 추가해줘"라고 요청)
def 파일_읽기_안전(파일경로):
    try:
        with open(파일경로, 'r', encoding='utf-8') as f:
            내용 = f.read()
        return 내용
    except FileNotFoundError:
        print(f"오류: '{파일경로}' 파일을 찾을 수 없습니다.")
        return None
```

## 자주 하는 실수

| 실수 | 에러 메시지 또는 증상 | 원인 | 해결법 |
|---|---|---|---|
| `input()` 결과를 숫자로 변환 안 함 | `TypeError: unsupported operand type(s) for +: 'str' and 'int'` | `input()`은 항상 문자열 반환 | `int(input(...))` 또는 `float(input(...))` 사용 |
| AI 코드를 이해 없이 그냥 실행 | 코드가 작동하다가 갑자기 이상한 결과 출력 | 코드 로직을 모르니 문제를 발견 못 함 | 코드를 줄별로 설명해보는 습관 들이기 |
| 프롬프트를 너무 길고 복잡하게 씀 | AI가 엉뚱한 코드를 생성 | 요구사항이 불명확하면 AI도 방황 | 기능 하나씩 쪼개서 요청 |
| 들여쓰기(indent) 오류 | `IndentationError: expected an indented block` | AI 코드 복사 시 공백이 탭/스페이스 혼용 | VS Code에서 '공백으로 들여쓰기 변환' 사용 |
| 없는 파일 경로 사용 | `FileNotFoundError: [Errno 2] No such file or directory` | 파일 경로가 틀림 | `os.path.exists(경로)`로 먼저 확인 |
| AI가 필요 없는 라이브러리를 import | `ModuleNotFoundError: No module named 'xxx'` | AI가 과도하게 라이브러리를 추가 | 사용하지 않는 import 줄 삭제 |
