## 이 장에서 배우는 것

- Claude, GitHub Copilot, Cursor가 각각 어떤 도구인지 이해한다
- 세 도구의 강점과 약점을 비교할 수 있다
- 내가 하려는 작업에 맞는 도구를 스스로 선택할 수 있다
- 실제 코딩 상황에서 도구를 조합해서 활용하는 방법을 안다

---

## 먼저 쉬운 설명

도구함에 망치, 드라이버, 줄자가 있다고 생각해 보세요. 못을 박을 때는 망치를 쓰고, 나사를 돌릴 때는 드라이버를 씁니다. 드라이버로 못을 박으려고 하면 시간이 두 배로 걸리죠.

AI 코딩 도구도 똑같습니다. Claude, GitHub Copilot, Cursor는 모두 "AI 코딩 도우미"이지만, 각자 잘하는 일이 다릅니다.

처음 배울 때는 "이게 다 비슷한 거 아닌가?"라고 느낄 수 있어요. 하지만 실제로 써보면 차이가 확연히 납니다. 이 장에서는 그 차이를 배우고, 상황에 맞게 올바른 도구를 고르는 눈을 기릅니다.

## 1. 세 도구 한눈에 비교하기

각 도구의 핵심 특징을 먼저 정리해 봅시다.

| 도구 | 주요 역할 | 사용 방식 | 비용 |
|------|-----------|-----------|------|
| **Claude** | 대화형 AI 어시스턴트 | 웹 브라우저 / API / Claude Code CLI | 무료 플랜 있음 |
| **GitHub Copilot** | 에디터 내 코드 자동완성 | VS Code, JetBrains 등 플러그인 | 월 구독 (학생 무료) |
| **Cursor** | AI 내장 코드 에디터 | 독립 실행형 에디터 앱 | 무료 플랜 있음 |

아래 파이썬 코드로 예시를 보겠습니다.

```python
# 파일명: tool_selector.py

def greet_user(name):
    """사용자에게 인사하는 함수"""
    return f"안녕하세요, {name}님!"

print(greet_user("지수"))
```

이 코드를 작성할 때 세 도구는 다음과 같이 도와줍니다.

- **Claude**: "이 함수를 더 좋게 만들려면 어떻게 해야 해요?" 라고 질문하면 전체적인 개선 방향을 설명해 줍니다.
- **Copilot**: `def greet_user(` 를 입력하는 순간 나머지 코드를 회색 글씨로 제안합니다.
- **Cursor**: 에디터 안에서 `Ctrl+K` 를 누르고 "인사 함수 만들어줘"라고 입력하면 코드를 바로 생성해 줍니다.

## 2. Claude — 긴 대화와 설명이 필요할 때

Claude는 **대화형** 도구입니다. 코드를 한 줄씩 완성해 주기보다는, 질문에 답하고 설명해 주고 전략을 같이 고민하는 데 강합니다.

**Claude가 잘하는 일:**
- 에러 메시지를 복사해서 "이게 왜 뜨나요?"라고 물어보기
- 코드 전체를 붙여넣고 "리뷰해줘"라고 요청하기
- "이 기능을 어떻게 만들면 좋을까요?"처럼 설계 질문하기
- 긴 파일을 읽고 요약하거나 버그를 찾아 달라고 하기

```python
# 파일명: debug_example.py

# 아래 코드에 버그가 있습니다. Claude에게 붙여넣고 "버그 찾아줘"라고 해보세요.

def calculate_average(numbers):
    total = 0
    for num in numbers:
        total = total + num
    # 실수: 리스트가 비어 있으면 ZeroDivisionError 발생
    return total / len(numbers)

scores = []
print(calculate_average(scores))
```

Claude에게 이 코드를 보여주면 다음과 같이 설명해 줍니다.

> "리스트가 비어 있을 때 `len(numbers)`가 0이 되어 ZeroDivisionError가 발생합니다. `if not numbers: return 0` 조건을 추가하세요."

**Claude Code CLI**를 사용하면 터미널에서 바로 Claude와 대화하면서 파일을 수정할 수도 있습니다.

```bash
# 터미널에서 Claude Code 실행
claude

# 이후 대화창에서:
# "debug_example.py 파일의 버그를 고쳐줘"
```

## 3. GitHub Copilot — 코드를 빠르게 타이핑할 때

Copilot은 **자동완성** 도구입니다. 에디터(주로 VS Code) 안에 살면서, 내가 코드를 입력하는 동안 다음에 올 내용을 예측해서 제안합니다.

**Copilot이 잘하는 일:**
- 함수 이름만 쓰면 본문을 채워주기
- 주석을 영어나 한국어로 쓰면 코드를 생성해 주기
- 반복적인 코드 패턴을 빠르게 완성하기

```python
# 파일명: copilot_demo.py

# Copilot이 있다면, 아래 주석을 쓰고 Enter를 눌러보세요.
# 학생 이름과 점수를 딕셔너리로 반환하는 함수

def create_student_record(name, score):
    # Copilot이 여기서 자동으로 코드를 제안합니다
    return {
        "name": name,
        "score": score,
        "grade": "A" if score >= 90 else "B" if score >= 80 else "C"
    }
```

**Tab 키**를 누르면 제안을 수락하고, `Esc` 를 누르면 거절합니다.

> **주의**: Copilot은 항상 옳지 않습니다. 제안된 코드를 반드시 읽고 이해한 다음 수락하세요.

## 4. Cursor — 에디터와 AI를 함께 쓰고 싶을 때

Cursor는 VS Code를 기반으로 만든 **AI 내장 에디터**입니다. Copilot처럼 자동완성도 되고, Claude처럼 대화도 되고, 파일 전체를 AI가 직접 수정해 주기도 합니다.

**Cursor가 잘하는 일:**
- `Ctrl+K`: 선택한 코드를 AI가 직접 수정
- `Ctrl+L`: 채팅창 열기 (Claude, GPT-4 등 선택 가능)
- `@파일명`: 특정 파일을 대화에 포함시키기
- 여러 파일에 걸친 변경 한 번에 처리하기

```python
# 파일명: cursor_demo.py

# Cursor에서 이 함수를 선택한 뒤 Ctrl+K를 누르고
# "타입 힌트 추가해줘"라고 입력해 보세요.

def multiply(a, b):
    return a * b

# Cursor가 아래처럼 바꿔줍니다:
def multiply(a: int | float, b: int | float) -> int | float:
    return a * b
```

## 5. 어떤 상황에서 어떤 도구를 쓸까?

실제 상황별로 정리하면 이렇습니다.

```python
# 파일명: situation_guide.py

"""
상황 1: 에러가 났는데 이유를 모르겠다
→ Claude에게 에러 메시지와 코드를 붙여넣고 물어보기

상황 2: 함수를 빠르게 많이 써야 한다
→ Copilot 자동완성 사용

상황 3: 코드 여러 줄을 한 번에 바꾸고 싶다
→ Cursor에서 선택 후 Ctrl+K

상황 4: 프로젝트 구조를 어떻게 잡을지 모르겠다
→ Claude에게 설계 질문

상황 5: 에디터를 바꾸기 싫지만 AI 기능을 쓰고 싶다
→ 현재 에디터에 Copilot 설치
"""
```

**조합해서 쓰는 것이 가장 좋습니다.** 예를 들어:

1. Claude와 대화하며 전체 구조 설계
2. Cursor 또는 Copilot으로 코드 빠르게 작성
3. 막히면 다시 Claude에게 질문

## 따라 하기 실습

### 실습 1 — Claude에게 코드 리뷰 요청하기

아래 파일을 만들고 Claude에게 리뷰를 요청해 봅니다.

```python
# 파일명: my_calculator.py

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def divide(a, b):
    return a / b  # 버그가 숨어 있습니다!

print(divide(10, 0))
```

1. 위 코드를 `my_calculator.py`로 저장합니다.
2. Claude 웹 또는 Claude Code CLI를 엽니다.
3. 코드 전체를 붙여넣고 이렇게 입력합니다:

   > "이 코드에 문제가 있나요? 초보자가 이해하기 쉽게 설명해 주세요."

4. Claude의 답변을 읽고, 지적된 부분을 직접 수정해 봅니다.

```python
# 학생을 추가하는 함수

# 학생 목록을 출력하는 함수
```

1. 파일을 만들고 주석을 한 줄씩 입력합니다.
2. 주석 아래에서 AI가 제안하는 코드를 확인합니다.
3. `Tab` 으로 수락하거나 `Esc` 로 거절해 보면서 자동완성 흐름을 익힙니다.

## 자주 하는 실수

| 실수 | 증상 / 에러 메시지 | 해결 방법 |
|------|-------------------|-----------|
| AI가 준 코드를 이해 없이 그대로 복사 | 나중에 수정해야 할 때 무엇을 고쳐야 할지 모름 | AI 코드를 한 줄씩 읽고 이해한 다음 수락한다 |
| Copilot 제안을 습관적으로 Tab | `TypeError`, `NameError` 등 예상치 못한 에러 발생 | 제안된 코드를 2~3초라도 읽고 수락 여부를 판단한다 |
| Claude에게 너무 짧게 질문 | 엉뚱한 답변이 돌아옴 ("어떤 언어인지 알려주세요") | 코드, 에러 메시지, 상황을 함께 붙여넣어 질문한다 |
| Cursor 없이 Copilot을 설치하려고 Cursor 앱 스토어 검색 | 앱을 찾지 못함 | Copilot은 VS Code 확장(Extension)으로 설치, Cursor는 cursor.sh에서 별도 설치 |
| AI 답변을 무조건 신뢰 | 잘못된 코드가 프로덕션에 배포됨 | AI는 틀릴 수 있다. 반드시 코드를 실행해서 결과를 확인한다 |
| 도구 선택 없이 무작정 시작 | 시간이 두 배로 걸림 | 작업 성격에 따라 도구를 먼저 정하고 시작한다 |
