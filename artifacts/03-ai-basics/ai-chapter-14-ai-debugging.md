## 이 장에서 배우는 것

- 파이썬 에러 메시지를 읽고 AI에게 올바르게 질문하는 방법
- 에러 메시지를 복사해서 AI 디버깅 어시스턴트에 붙여넣는 방법
- AI가 알려준 수정 방법을 코드에 직접 적용하는 방법
- AI에게 "왜 틀렸는지"까지 설명 요청하는 방법
- 같은 실수를 반복하지 않도록 에러 패턴을 기억하는 방법

---

## 먼저 쉬운 설명

코딩을 배울 때 에러 메시지가 나오면 겁부터 납니다. 빨간 글씨가 줄줄이 나오면 "내가 뭔가 크게 잘못했나?" 싶죠.

하지만 에러 메시지는 **사실 매우 친절한 안내문**입니다. 어디서, 무엇이, 왜 잘못됐는지 정확히 알려주고 있습니다. 우리가 아직 그 언어를 잘 못 읽을 뿐이에요.

AI 디버깅 어시스턴트를 쓰면 에러 메시지를 그대로 붙여넣기만 해도 "이건 이런 이유로 생긴 에러고, 이렇게 고치면 돼"라고 바로 알려줍니다. 구글에서 검색해서 스택오버플로우 글을 읽는 것보다 훨씬 빠르고, 내 코드에 맞게 설명해 줍니다.

이 장을 마치면 에러가 나도 "이제 AI한테 물어보면 되지"라는 자신감이 생깁니다.

## 1. 에러 메시지 구조 읽기

에러가 나면 파이썬은 아래 형식으로 알려줍니다.

```
Traceback (most recent call last):
  File "파일이름.py", line 줄번호, in 함수이름
    문제가 된 코드
에러종류: 에러 설명
```

**실제 예시 — `user_score.py`**

```python
# user_score.py
def print_score(name, score):
    print(name + "님의 점수는 " + score + "점입니다.")

print_score("김민준", 95)
```

실행하면 다음 에러가 납니다.

```
Traceback (most recent call last):
  File "user_score.py", line 3, in print_score
    print(name + "님의 점수는 " + score + "점입니다.")
TypeError: can only concatenate str (not "int") to str
```

에러 메시지를 읽는 순서:

1. **`File "user_score.py", line 3`** → 3번째 줄에서 문제 발생
2. **`TypeError`** → 타입(자료형) 관련 에러
3. **`can only concatenate str (not "int") to str`** → 문자열에 정수를 붙일 수 없다

이 세 가지를 AI에게 그대로 전달하면 됩니다.

---

## 2. AI에게 올바르게 질문하는 방법

에러가 났을 때 AI에게 질문하는 방법에는 **좋은 방법**과 **나쁜 방법**이 있습니다.

### 나쁜 질문 예시

```
"코드가 안 돼요. 왜 그러죠?"
```

AI가 뭘 도와야 할지 모릅니다. 코드도 없고, 에러도 없으니까요.

### 좋은 질문 템플릿

```
다음 파이썬 코드를 실행했더니 에러가 났습니다.

[코드]
```python
# 여기에 내 코드 붙여넣기
```

[에러 메시지]
```
여기에 에러 메시지 전체 붙여넣기
```

이 에러가 왜 생겼는지, 어떻게 고치는지 초보자가 이해할 수 있게 설명해 주세요.
```

**실제 질문 예시 — `user_score.py` 기준**

```
다음 파이썬 코드를 실행했더니 에러가 났습니다.

[코드]
```python
def print_score(name, score):
    print(name + "님의 점수는 " + score + "점입니다.")

print_score("김민준", 95)
```

[에러 메시지]
```
TypeError: can only concatenate str (not "int") to str
```

이 에러가 왜 생겼는지, 어떻게 고치는지 초보자가 이해할 수 있게 설명해 주세요.
```

이렇게 물으면 AI는 "정수를 문자열로 바꾸려면 `str(score)`를 쓰거나 f-string을 쓰세요"라고 정확히 알려줍니다.

---

## 3. AI가 알려준 방법을 코드에 적용하기

AI가 두 가지 수정 방법을 알려줬다고 가정합니다.

**방법 1 — `str()` 로 변환**

```python
# user_score.py (수정 버전 1)
def print_score(name, score):
    print(name + "님의 점수는 " + str(score) + "점입니다.")

print_score("김민준", 95)
```

**방법 2 — f-string 사용 (더 권장)**

```python
# user_score.py (수정 버전 2)
def print_score(name, score):
    print(f"{name}님의 점수는 {score}점입니다.")

print_score("김민준", 95)
```

실행 결과:
```
김민준님의 점수는 95점입니다.
```

AI가 여러 방법을 알려줄 때는 **왜 그 방법이 더 좋은지도 같이 물어보세요.**

```
두 방법 중 어느 것이 더 좋은 방법인지, 왜 그런지도 알려주세요.
```

이렇게 하면 코드를 고치는 것에서 그치지 않고 **개념까지** 배울 수 있습니다.

## 4. 에러 패턴 기억하기 — 나만의 에러 노트

같은 에러를 계속 반복하지 않으려면 내가 겪은 에러를 기록해 두는 것이 좋습니다.

**`error_note.md` 파일을 만들어 정리하는 예시**

```markdown
# 내 에러 노트

## TypeError: can only concatenate str (not "int") to str
- **언제**: 문자열과 숫자를 + 로 이으려 할 때
- **원인**: 파이썬은 다른 자료형을 + 로 합칠 수 없음
- **해결**: str() 로 숫자를 문자열로 바꾸거나, f-string 사용
- **예시**: `f"{name}님의 점수는 {score}점입니다."`

## NameError: name 'x' is not defined
- **언제**: 변수를 만들기 전에 사용하려 할 때
- **원인**: 변수 선언 없이 사용
- **해결**: 변수를 먼저 선언한 뒤 사용
- **예시**: `x = 0` 을 print(x) 위에 추가
```

AI에게 "이 에러를 내 에러 노트에 정리하기 좋게 요약해 줘"라고 부탁하면 더 빠르게 정리할 수 있습니다.

## 따라 하기 실습

### 실습 1 — 에러 메시지 직접 만들고 AI에게 질문하기

1. `grade_checker.py` 파일을 만들고 아래 코드를 그대로 입력합니다.

```python
# grade_checker.py
scores = [85, 90, 78, 92, 88]
total = 0

for score in scores:
    total = total + score

average = total / len(scores)
print("평균 점수: " + average)
```

2. 터미널에서 실행합니다.

```bash
python grade_checker.py
```

3. 아래와 같은 에러가 나면 성공입니다.

```
TypeError: can only concatenate str (not "float") to str
```

4. 위의 **좋은 질문 템플릿**을 사용해서 AI에게 질문합니다. 코드와 에러 메시지를 모두 붙여넣는 것을 잊지 마세요.

---

### 실습 2 — AI가 알려준 방법으로 수정하고 다시 실행하기

실습 1에서 AI가 알려준 방법을 `grade_checker.py`에 직접 적용합니다.

1. AI가 알려준 방법으로 코드를 수정합니다. (힌트: f-string 또는 `str()`)
2. 다시 실행해서 에러 없이 결과가 나오는지 확인합니다.

```
평균 점수: 86.6
```

3. AI에게 아래 질문을 추가로 합니다.

```
f-string을 쓰면 소수점을 두 자리까지만 보이게 할 수 있나요?
파이썬 초보자가 이해할 수 있게 예시 코드와 함께 알려주세요.
```

4. AI가 알려준 방법을 적용해서 출력 결과를 아래처럼 만들어 보세요.

```
평균 점수: 86.60
```

### 실습 3 — 에러 노트 작성하기

1. 내 프로젝트 폴더에 `error_note.md` 파일을 만듭니다.
2. 실습 1과 2에서 겪은 에러를 AI에게 아래처럼 정리 요청합니다.

```
내가 오늘 겪은 에러를 아래 형식으로 정리해 줘.

## 에러 이름
- 언제:
- 원인:
- 해결:
- 예시 코드:
```

3. AI가 정리해 준 내용을 `error_note.md` 에 붙여넣습니다.

## 자주 하는 실수

| 실수 | 에러 메시지 | 해결 방법 |
|------|------------|----------|
| 에러 메시지 없이 "안 돼요"라고만 물어봄 | (AI가 도움 못 줌) | 코드와 에러 메시지를 **반드시** 같이 붙여넣기 |
| 에러 메시지 일부만 복사함 | AI가 엉뚱한 답을 줌 | `Traceback` 부터 마지막 줄까지 **전체** 복사 |
| AI가 고쳐준 코드를 이해 없이 붙여넣음 | 나중에 같은 에러 반복 | "왜 이렇게 고치는 건지 설명해 줘"도 꼭 물어보기 |
| 한 번에 여러 에러를 다 물어봄 | 답이 복잡하고 헷갈림 | 에러는 **하나씩** 물어보기 |
| 수정 후 저장 안 하고 실행 | 같은 에러 계속 발생 | 코드 수정 후 반드시 `Ctrl+S` (저장) 확인 |
| `IndentationError` 무시 | `IndentationError: unexpected indent` | 탭과 스페이스를 섞어 쓴 것이 원인, AI에게 들여쓰기 기준 물어보기 |
