# ai-train Module 03: AI가 만든 Python 초안 수정하기

## 이 장에서 배우는 것

- AI가 만든 Python 코드를 읽는 방법
- 잘못된 코드를 어떻게 찾는지
- 왜 수정했는지 설명하는 방법

## 먼저 쉬운 설명

AI는 Python 코드를 빨리 만들어 줄 수 있다.  
하지만 빠르게 만들었다고 해서 항상 정확한 것은 아니다.

초보자에게 중요한 것은:

- AI가 만든 코드를 그냥 복사하는 것보다
- 읽고, 고치고, 이유를 설명하는 연습을 하는 것이다

이 과정을 통해 진짜 실력이 쌓인다.

## 핵심 개념

### 1. 코드 읽기

먼저 아래를 본다.

- 함수 이름
- 입력값
- 출력값
- 반복문과 조건문

### 2. 이상한 부분 찾기

확인할 것:

- 값이 제대로 누적되는가
- 출력 형식이 맞는가
- 빈 입력에서 오류는 없는가
- 변수 이름이 이해되는가

### 3. 수정 이유 설명하기

수정만 하면 끝이 아니다.

다음까지 말할 수 있어야 한다.

- 무엇이 잘못됐는가
- 어떻게 고쳤는가
- 왜 더 좋아졌는가

## 따라 하기

### 실습 예시 코드

```python
def summarize_scores(items):
    total = 0
    for item in items:
        total = item["score"]
    avg = total / len(items)
    return {"average": avg, "count": items}
```

### 1단계. 문제 찾기

- `total`이 누적되지 않는다
- `count`에 숫자가 아니라 리스트가 들어간다
- 빈 리스트일 때 오류가 날 수 있다

### 2단계. 코드 수정하기

```python
def summarize_scores(items):
    if not items:
        return {"average": 0, "count": 0}

    total_score = 0
    for item in items:
        total_score += item["score"]

    average_score = total_score / len(items)
    return {"average": average_score, "count": len(items)}
```

### 3단계. 왜 수정했는지 적기

- 점수를 합치려면 값을 계속 더해야 하므로 `+=`가 필요하다
- 개수는 리스트 자체가 아니라 길이여야 한다
- 빈 입력도 안전하게 처리해야 한다

## 자주 하는 실수

- 코드가 짧으니 맞을 것이라고 생각하기
- 변수 이름이 이상해도 그냥 넘기기
- 예시 입력으로 테스트하지 않기
- 수정 이유를 설명하지 못하기

## 확인 체크리스트

- 입력과 출력이 무엇인지 말할 수 있는가
- 코드의 문제를 2개 이상 찾았는가
- 수정 후 예시 입력으로 확인했는가
- 왜 수정했는지 문장으로 설명할 수 있는가
