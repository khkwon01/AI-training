# ai-train AI Chapter 04: 좋은 프롬프트 작성법

## 이 장에서 배우는 것

- 프롬프트가 왜 중요한지
- 약한 프롬프트와 강한 프롬프트의 차이
- 역할, 목표, 제약, 형식을 포함한 프롬프트 구조
- 상황별 프롬프트 패턴 (코딩, 설명 요청, 검토 요청)
- 한 번에 원하는 결과를 얻는 대화 전략

---

## 먼저 쉬운 설명

AI에게 "파이썬 함수 만들어줘"라고 하면 어떤 결과가 나올까?

너무 막연해서 AI가 어떤 함수를 만들어야 할지 모른다. 레스토랑에서 "음식 주세요"라고 하는 것과 같다.

구체적으로 말할수록 원하는 결과가 나온다.

```
약한 프롬프트:
"파이썬 함수 만들어줘"

강한 프롬프트:
"Python으로 숫자 리스트를 입력받아 평균을 반환하는 함수를 만들어줘.
빈 리스트가 들어오면 0을 반환해야 해.
초보자도 이해할 수 있게 한국어 주석을 달아줘."
```

---

## 1. 프롬프트의 4가지 요소

좋은 프롬프트에는 보통 4가지가 포함된다.

| 요소 | 설명 | 예시 |
|------|------|------|
| **역할** | AI에게 어떤 역할을 맡길지 | "Python 초보자 교사처럼 설명해줘" |
| **목표** | 무엇을 만들거나 해야 하는지 | "평균을 계산하는 함수를 만들어줘" |
| **제약** | 조건이나 제한사항 | "빈 리스트면 0 반환, 주석 포함" |
| **형식** | 결과를 어떤 형태로 줄지 | "코드 블록과 한 줄 설명으로" |

모두 있어야 하는 건 아니다. 상황에 따라 필요한 것만 추가한다.

---

## 2. 코딩 요청 프롬프트

### 기본 패턴

```
[언어]로 [기능]을 하는 [결과물 종류]을 만들어줘.
[조건 1], [조건 2].
[형식 요청].
```

### 실제 예시

**약한 버전:**
```
검색 기능 만들어줘
```

**강한 버전:**
```
Python으로 문자열 리스트에서 특정 키워드가 포함된 항목만 반환하는
search_items(items, keyword) 함수를 만들어줘.
- keyword가 빈 문자열이면 전체 리스트를 반환해야 해
- 대소문자를 구분하지 않아야 해
- 함수에 docstring을 포함해줘
```

---

## 3. 설명 요청 프롬프트

코드나 개념을 설명받을 때.

```
아래 Python 코드를 초보자도 이해할 수 있게 한 줄씩 설명해줘.
전문 용어는 쉬운 말로 바꿔서 설명해줘.

[코드 붙여넣기]
```

```
Python의 list comprehension이 무엇인지 설명해줘.
- 반복문과 비교해서 차이를 보여줘
- 간단한 예시 2개 포함
- 언제 쓰면 좋고 언제 쓰면 안 좋은지도 알려줘
```

---

## 4. 검토 요청 프롬프트

내가 작성한 코드를 검토받을 때.

```
아래 Python 코드를 검토해줘.
개선할 점이 있으면 구체적으로 알려줘.
초보자 수준의 코드라고 생각하고 설명해줘.

[코드 붙여넣기]
```

더 구체적으로:

```
아래 코드에서 아래 항목을 체크해줘:
1. 오류가 발생할 수 있는 부분
2. 더 Pythonic하게 쓸 수 있는 부분
3. 빠진 예외 처리

[코드 붙여넣기]
```

---

## 5. 오류 해결 프롬프트

오류가 났을 때.

```
Python 코드를 실행했더니 아래 오류가 나왔어.
오류 원인을 설명하고 수정 방법을 알려줘.

[오류 메시지]

[오류가 난 코드]
```

추가 컨텍스트 주기:

```
memo.py를 실행하다가 아래 오류가 났어.
파일을 읽는 부분에서 발생한 것 같아.

오류 메시지:
FileNotFoundError: [Errno 2] No such file or directory: 'memos.json'

관련 코드:
with open("memos.json", "r") as f:
    memos = json.load(f)
```

## 6. 이전 결과를 이어받는 대화

AI와의 대화는 앞 내용을 기억한다. 이전 결과를 발판으로 쓸 수 있다.

```
# 1번째 요청
Python으로 메모 추가 함수 add_memo를 만들어줘.

# 결과 확인 후 2번째 요청
좋아. 이제 이 함수에 중복 체크를 추가해줘.
같은 내용의 메모가 이미 있으면 추가하지 않고 경고 메시지를 출력해.

# 3번째 요청
그리고 이 함수에 대한 간단한 테스트 코드도 만들어줘.
성공 케이스 1개, 중복 케이스 1개를 테스트해야 해.
```

## 7. 약한 프롬프트 vs 강한 프롬프트 비교

| 상황 | 약한 프롬프트 | 강한 프롬프트 |
|------|------------|------------|
| 함수 만들기 | "함수 만들어줘" | "Python으로 두 숫자를 더하는 add(a, b) 함수를 만들어줘. 두 인수가 숫자가 아닐 때 TypeError를 발생시켜야 해." |
| 오류 해결 | "오류 고쳐줘" | "NameError: name 'memos' is not defined 오류가 나왔어. 아래 코드에서 원인을 찾아줘. [코드]" |
| 설명 요청 | "설명해줘" | "이 코드에서 enumerate가 하는 역할을 Python 처음 배우는 사람에게 설명하듯 간단하게 알려줘." |

## 8. 따라 하기 실습

### 실습 1. 같은 요청을 두 가지 방식으로

아래 두 가지 방식으로 AI에게 요청하고 결과를 비교해본다.

**방식 A:**
```
리스트 정렬해줘
```

**방식 B:**
```
Python 리스트 [3, 1, 4, 1, 5, 9, 2, 6]을 오름차순으로 정렬하는 코드를 만들어줘.
원본 리스트를 변경하지 않고 새 리스트를 반환해야 해.
sorted()와 list.sort()의 차이도 설명해줘.
```

어떤 방식이 더 유용한 결과를 줬는지 비교한다.

### 실습 2. 내가 작성한 코드 검토 받기

Chapter 14에서 만든 `BankAccount` 클래스 코드를 AI에게 보내고:

```
아래 Python 코드를 검토해줘.
1. 오류가 발생할 수 있는 부분
2. 추가하면 좋을 기능
을 알려줘. 초보자 수준이라고 생각하고 설명해줘.

[BankAccount 코드 붙여넣기]
```

### 실습 3. 오류 메시지로 해결 요청하기

의도적으로 오류를 만들고, 오류 메시지와 코드를 함께 AI에게 보내서 해결 방법을 받아본다.
