# ai-train Service Planning Workbook 01

## 목표

AI를 사용해 만들 서비스의 아이디어를 아주 작고 쉬운 수준으로 정리해 본다.

## 이 워크북이 필요한 이유

초보자가 서비스를 만들 때 가장 먼저 어려워하는 것은

- 무엇을 만들지
- 얼마나 작게 시작할지
- 어떤 기능부터 만들지

를 정하는 일이다.

그래서 이 워크북은 "바로 코딩 시작"이 아니라  
"작게 정리하고, 작게 부탁하고, 작게 확인하는 방법"을 연습하게 한다.

## 1단계. 서비스 한 줄 설명

예:

```text
오늘 할 일과 메모를 저장하는 작은 웹 서비스
```

직접 적어 보기:

```text
내가 만들 서비스 한 줄 설명:
________________________________
```

## 2단계. 사용자 1명 정하기

예:

```text
혼자 공부하는 중학생
```

직접 적어 보기:

```text
이 서비스를 쓸 사람:
________________________________
```

## 3단계. 첫 기능 1개만 고르기

좋은 예:

- 메모 1개 저장하기
- 오늘 할 일 1개 추가하기
- 저장된 목록 보여 주기

너무 큰 예:

- 로그인, 알림, 공유, 배포를 한 번에 다 만들기

직접 적어 보기:

```text
첫 번째로 만들 기능:
________________________________
```

## 4단계. AI에게 작은 요청 만들기

예:

```text
초보자를 위해 Python으로 메모 1개를 저장하는 아주 작은 기능 예제를 만들어줘.
코드는 짧게 쓰고, 줄마다 쉬운 설명을 붙여줘.
```

## 5단계. 결과를 검토할 기준 정하기

확인할 것:

- 기능이 한 가지인가
- 코드가 짧은가
- 설명이 쉬운가
- 내가 이해하지 못한 줄은 없는가

## 6단계. 다음 단계 적기

예:

```text
다음에는 저장된 메모 목록을 보여 주는 기능을 추가한다.
```

## 확인 체크리스트

- 서비스 설명이 한 줄로 끝나는가
- 첫 기능이 너무 크지 않은가
- AI 요청이 작고 구체적인가
- 결과를 검토할 기준이 있는가
