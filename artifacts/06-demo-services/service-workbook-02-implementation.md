## 1. 서비스 아이디어를 한 문장으로 쓰기

### 왜 한 문장인가요?

아이디어가 길고 복잡할수록 코드로 옮기기 어렵습니다. 한 문장으로 쓰는 연습을 하면 핵심이 명확해집니다.

### 좋은 예시와 나쁜 예시

```
나쁜 예시:
"사람들이 할 일을 관리하고, 일정도 보고, 팀원과 공유하고,
 알림도 받고, 통계도 볼 수 있는 앱"

좋은 예시:
"사용자가 할 일을 추가하고 완료 표시를 할 수 있는 앱"
```

### 내 서비스 아이디어 작성 칸

```
나의 서비스 한 문장:
______________________________________________________
______________________________________________________
```

### 예시 코드 — 서비스 아이디어를 주석으로 남기기

```python
# todo_app.py

# 서비스 설명: 사용자가 할 일을 추가하고 완료 표시를 할 수 있는 앱

할일_목록 = []

def 할일_추가(내용):
    할일_목록.append({"내용": 내용, "완료": False})
    print(f"추가됨: {내용}")

def 할일_보기():
    for i, 항목 in enumerate(할일_목록):
        상태 = "✅" if 항목["완료"] else "⬜"
        print(f"{i+1}. {상태} {항목['내용']}")

할일_추가("장보기")
할일_추가("운동하기")
할일_보기()
```

**실행 결과:**
```
추가됨: 장보기
추가됨: 운동하기
1. ⬜ 장보기
2. ⬜ 운동하기
```

## 3. AI에게 코드 요청하기

### 좋은 요청문의 구조

AI에게 막연하게 "코드 짜줘"라고 하면 내가 원하는 결과가 나오지 않을 수 있습니다. 아래 구조로 요청하면 훨씬 좋은 결과를 얻을 수 있습니다.

```
요청문 구조:
[언어/환경] + [무엇을 만드는지] + [입력은 무엇인지] + [출력은 무엇인지] + [특별한 조건]
```

### 요청문 예시 비교

```
나쁜 요청:
"할 일 앱 코드 만들어줘"

좋은 요청:
"Python으로 할 일을 추가하는 함수를 만들어줘.
 입력: 할 일 내용 문자열
 출력: 번호, 내용, 완료 여부(False)가 담긴 딕셔너리를 리스트에 추가
 조건: 빈 문자열은 추가하지 않고 '내용을 입력하세요' 메시지 출력"
```

## 4. AI 결과 검토하기

### 코드를 받으면 바로 실행하기 전에 먼저 읽어보세요

```python
# AI가 만들어준 코드 예시
def 할일_추가(내용):
    if not 내용.strip():          # ← 이 줄이 뭘 하는지 이해했나요?
        print("내용을 입력하세요")
        return
    할일_목록.append({
        "번호": len(할일_목록) + 1,
        "내용": 내용,
        "완료": False
    })
    print(f"✅ '{내용}' 추가됨")
```

### 결과 검토 체크 칸

```
1. 코드를 실행했나요?
   □ 실행했다   □ 아직 못 했다

2. 실행 결과:
   □ 잘 됐다
   □ 오류가 났다 → 오류 메시지: ______________________

3. 내가 기대했던 결과와 같은가요?
   □ 같다
   □ 다르다 → 어떻게 다른지: _________________________

4. 이해가 안 되는 코드 줄이 있나요?
   □ 없다 (모두 이해했다)
   □ 있다 → 어떤 줄인지: _____________________________
```

        return
    할일_목록.append({"내용": 내용, "완료": False})

# ⬜ 다음에 만들 기능

    pass  # 나중에 구현

# ⬜ 그 다음 기능

# my_service.py

### 실습 2 — AI에게 첫 기능 코드 요청하고 붙여넣기

**파일 이름:** `my_service.py` (실습 1에서 계속)

1. 위에서 작성한 '내가 AI에게 보낼 요청문'을 AI에게 그대로 보내세요.
2. AI가 준 코드를 `첫번째_기능` 함수 자리에 붙여넣으세요.
3. `if __name__ == "__main__":` 아래에 테스트 코드를 추가하세요.

```python
# 완성 예시 (책 기록 앱의 경우)
책_목록 = []

def 책_추가(제목):
    if not 제목.strip():
        print("제목을 입력하세요")
        return
    책_목록.append({"제목": 제목, "감상": "", "날짜": "2026-05-14"})
    print(f"'{제목}' 기록됨")

if __name__ == "__main__":
    책_추가("파친코")
    책_추가("채식주의자")
    책_추가("")          # 빈 문자열 테스트
    print(f"총 {len(책_목록)}권 기록됨")
```

**확인:** 오류 없이 실행되고, 빈 문자열을 넣었을 때 `"제목을 입력하세요"`가 출력되면 성공입니다.

## 자주 하는 실수

| 실수 | 오류 메시지 / 증상 | 해결 방법 |
|---|---|---|
| 함수를 정의만 하고 호출 안 함 | 아무것도 출력이 안 됨 | `함수이름()` 으로 호출하는 코드 추가 |
| 들여쓰기를 탭과 스페이스 섞어 씀 | `TabError: inconsistent use of tabs and spaces` | 에디터에서 '탭을 스페이스로 변환' 설정 켜기 |
| 한글 변수명에 공백 넣음 | `SyntaxError: invalid syntax` | 변수명에 공백 없애기: `할 일` → `할일` |
| `pass` 지우는 것 잊음 | 함수를 호출해도 아무 일도 안 일어남 | `pass` 줄을 실제 코드로 교체 |
| AI 코드를 전혀 이해 안 한 채로 붙여넣음 | 나중에 수정할 때 어디를 고쳐야 할지 모름 | 한 줄씩 읽으면서 모르는 줄은 AI에게 설명 요청 |
| 첫 기능부터 너무 복잡하게 만들려 함 | 코드가 너무 길어져서 오류 찾기가 어려워짐 | 기능을 더 작게 나누고 하나씩 완성하기 |
| 파일 저장을 안 하고 실행 | 수정이 반영 안 되는 것처럼 보임 | `Ctrl+S` (또는 `Cmd+S`) 로 저장 후 실행 |
