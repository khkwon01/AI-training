## 이 장에서 배우는 것

- 메모 삭제(delete)가 무엇인지 이해한다
- 목록에서 특정 메모 1개를 지우는 코드를 읽고 설명할 수 있다
- `filter`를 사용해 원하는 항목만 남기는 방법을 배운다
- 이전 장에서 만든 메모 목록과 자연스럽게 연결해 기능을 확장한다

---

## 먼저 쉬운 설명

지금까지 메모를 **추가**하고 **조회**하는 기능을 만들었다. 그런데 메모가 쌓이다 보면 필요 없는 메모를 **지우고 싶어진다**.

삭제는 간단하다. "이 메모는 필요 없어"라고 말하면, 목록에서 그 메모만 골라서 빼내는 것이다.

코드에서는 `filter`라는 도구를 자주 쓴다. 필터는 "조건에 맞는 것만 남겨줘"라는 뜻이다. 예를 들어 "id가 3인 메모 빼고 나머지 전부 남겨줘"라고 하면 그게 삭제와 같은 효과가 된다.

---

## 1. 메모 목록 준비하기

삭제를 실습하기 전에, 지금까지 만든 메모 목록을 그대로 사용한다.

```js
// memo_service.js

let memos = [
  { id: 1, content: "우유 사기" },
  { id: 2, content: "운동하기" },
  { id: 3, content: "책 읽기" },
];
```

`memos`는 메모 객체들이 담긴 배열이다. 각 메모에는 고유 번호(`id`)와 내용(`content`)이 있다. 삭제할 때는 이 `id`를 기준으로 찾는다.

---

## 2. 삭제 함수 만들기

이제 특정 `id`를 가진 메모를 지우는 함수를 만든다.

```js
// memo_service.js (이어서 작성)

function deleteMemo(id) {
  const 이전개수 = memos.length;

  memos = memos.filter((memo) => memo.id !== id);

  const 이후개수 = memos.length;

  if (이전개수 === 이후개수) {
    console.log(`id가 ${id}인 메모를 찾을 수 없습니다.`);
  } else {
    console.log(`id가 ${id}인 메모를 삭제했습니다.`);
  }
}
```

**핵심 한 줄:**

```js
memos = memos.filter((memo) => memo.id !== id);
```

- `filter`는 조건이 `true`인 항목만 모아서 **새 배열**을 만든다
- `memo.id !== id`는 "삭제할 id와 다른 메모만 남겨줘"라는 뜻이다
- 결과적으로 원하는 메모 1개가 목록에서 빠진다

---

## 3. 삭제 함수 사용해 보기

```js
// memo_service.js (이어서 작성)

console.log("삭제 전:", memos);

deleteMemo(2); // "운동하기" 삭제

console.log("삭제 후:", memos);
```

실행 결과:

```
삭제 전: [
  { id: 1, content: '우유 사기' },
  { id: 2, content: '운동하기' },
  { id: 3, content: '책 읽기' }
]
id가 2인 메모를 삭제했습니다.
삭제 후: [
  { id: 1, content: '우유 사기' },
  { id: 3, content: '책 읽기' }
]
```

`id: 2`인 "운동하기" 메모가 깔끔하게 사라졌다.

---

## 4. 없는 메모를 삭제하려 하면?

존재하지 않는 `id`로 삭제를 시도하면 어떻게 되는지 확인해 보자.

```js
deleteMemo(99); // 없는 id
```

실행 결과:

```
id가 99인 메모를 찾을 수 없습니다.
```

`filter`는 조건에 맞는 항목이 없어도 오류를 내지 않는다. 그냥 원래 배열을 그대로 반환한다. 그래서 삭제 전후 개수를 비교해서 실제로 삭제됐는지 확인하는 것이 중요하다.

---

## 5. 전체 코드 정리

지금까지 작성한 내용을 하나의 파일로 합쳐 보자.

```js
// memo_service.js

let memos = [
  { id: 1, content: "우유 사기" },
  { id: 2, content: "운동하기" },
  { id: 3, content: "책 읽기" },
];

function deleteMemo(id) {
  const 이전개수 = memos.length;
  memos = memos.filter((memo) => memo.id !== id);
  const 이후개수 = memos.length;

  if (이전개수 === 이후개수) {
    console.log(`id가 ${id}인 메모를 찾을 수 없습니다.`);
  } else {
    console.log(`id가 ${id}인 메모를 삭제했습니다.`);
  }
}

// 테스트
console.log("삭제 전:", memos);
deleteMemo(2);
console.log("삭제 후:", memos);
deleteMemo(99);
console.log("최종 목록:", memos);
```

## 따라 하기 실습

### 실습 1 — 파일 만들고 기본 코드 실행하기

1. `memo_service.js` 파일을 새로 만든다
2. 위의 "전체 코드 정리" 내용을 그대로 붙여넣는다
3. 터미널에서 실행한다

```bash
node memo_service.js
```

결과에 "삭제했습니다"와 "찾을 수 없습니다" 두 문장이 모두 출력되면 성공이다.

---

### 실습 2 — 삭제 대상을 바꿔 보기

`deleteMemo(2)` 부분을 `deleteMemo(1)`로 바꿔서 실행해 본다.

```js
deleteMemo(1); // "우유 사기" 삭제
```

`console.log("삭제 후:", memos)`의 결과를 확인하고, 남은 메모가 `id: 2`와 `id: 3`인지 직접 눈으로 확인한다.

---

### 실습 3 — 메모를 추가한 뒤 삭제하기

아래 코드를 파일 맨 아래에 추가해 본다.

```js
// 새 메모 추가
memos.push({ id: 4, content: "친구에게 전화하기" });
console.log("추가 후:", memos);

// 방금 추가한 메모 삭제
deleteMemo(4);
console.log("다시 삭제 후:", memos);
```

추가했다가 바로 삭제하면 목록이 원래대로 돌아오는지 확인한다. 이 흐름이 실제 서비스에서 "생성 → 삭제" 사이클이다.

## 자주 하는 실수

| 실수 | 오류 메시지 / 잘못된 결과 | 원인 | 해결 방법 |
|------|--------------------------|------|-----------|
| `filter` 결과를 `memos`에 다시 저장하지 않음 | 삭제해도 목록이 그대로임 | `filter`는 원본을 바꾸지 않고 새 배열을 반환함 | `memos = memos.filter(...)` 처럼 반드시 재할당 |
| `!==` 대신 `===` 를 사용 | 삭제하려는 메모만 남고 나머지가 전부 사라짐 | 조건 방향이 반대임 | `memo.id !== id` 로 수정 |
| 숫자 id를 문자열로 비교 | `id가 2인 메모를 찾을 수 없습니다.` 가 뜸 | `"2" !== 2` 는 `true` 이므로 아무것도 삭제 안 됨 | `deleteMemo(2)` 처럼 따옴표 없이 숫자로 전달 |
| `const` 로 선언된 `memos` 에 재할당 시도 | `TypeError: Assignment to constant variable.` | `const` 는 재할당 불가 | `memos` 선언을 `let` 으로 변경 |

---

## 확인 체크리스트

- [ ] `filter`가 원본 배열을 바꾸지 않는다는 것을 이해했다
- [ ] `memos = memos.filter(...)` 처럼 결과를 다시 저장해야 하는 이유를 말할 수 있다
- [ ] `memo.id !== id` 조건이 왜 삭제 역할을 하는지 설명할 수 있다
- [ ] 존재하지 않는 id를 삭제해도 오류가 나지 않는 이유를 안다
- [ ] `node memo_service.js` 를 실행해서 삭제 결과를 직접 확인했다
- [ ] 메모를 추가한 뒤 삭제하는 실습 3까지 완료했다
